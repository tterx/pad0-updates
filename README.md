# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_21.zip)

기존 프로그램을 종료하고 `시작.vbs`로 다시 실행하면 최신 버전을 확인합니다. 새 설치는 ZIP을 새 폴더에 압축 해제한 뒤 실행합니다. 설정과 개인 DB는 기존 LocalAppData/Pad0Overlay에서 읽으며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.21: **F7에서는 전체 재료 목록을 펼쳐 보여주고, 이후 상세 이름 등록은 관리창을 숨긴 채 뒤에서 처리합니다.** 첫 F7의 강제 상단 고정을 제거했습니다. 기존 자동 고정은 최초 한 번 해제하고 이후 수동 고정 선택은 유지합니다.

최대 5개 재료와 수량이 한 번에 들어가도록 창 크기를 맞추며 제목을 피하기 위한 위치 제한은 제거했습니다. 자동 인식 중에는 관리창 크기에 관계없이 먼저 숨기고 캡처합니다. 완료·실패·취소 후 창을 다시 띄우거나 앞으로 올리지 않습니다. 목록을 보려면 메인창에서 크리스탈 창을 다시 열면 됩니다. [사용 안내](FARMING_STATS.md#전체-목록-확인-후-백그라운드-등록-v10121)

아텐 이름 저장·기존 이미지 연결·돌파 대상 이미지 표시를 유지합니다. 게임 창 자체의 이동·크기 변경 후에는 돌파 화면에서 F7로 기준을 다시 읽습니다.

회귀 테스트 201개 및 실제 Tk에서 5행 전체 표시, 500x250 축소 창의 자동 등록, show/lift 호출 없이 뒤에서 갱신, 수동 재열기 시 목록 전체 확장 확인. Windows/MuMu 실기기 동작은 별도 확인이 필요합니다.

수동 경로 조건 6종을 유지합니다. 파티와 팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 아직 미적용입니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
