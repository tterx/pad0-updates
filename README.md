# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_29.zip)

프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 개인 DB와 설정은 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 **v101.29**: 돌파 확인 화면의 맨 위 제목 오른쪽에 **재료확인** 버튼을 추가했습니다. 일반·초·초절·최종 한계 돌파 확인에서만 표시하고 다른 화면이나 다른 프로그램으로 전환하면 숨깁니다. 게임 창 위치와 크기를 따라갑니다.

버튼을 누르면 즉시 ‘확인 중…’으로 바뀐 뒤 기존 F7과 같은 등록 기능을 실행합니다. F7도 계속 사용할 수 있습니다. OCR 처리 시간 자체를 생략하지는 않습니다. 레이아웃과 상단 제목을 확인하고 같은 제목은 재사용합니다. 클릭 직전 창·페이지 재검증, 중복 OCR 방지, 제목 확인과 F7 인식 충돌 방지를 적용했습니다. [사용 안내](FARMING_STATS.md#돌파-확인-화면의-재료확인-버튼-v10129)

테스트 280개 통과. 재현 배치의 실제 한국어 OCR, 창 전환과 페이지 종료/재진입, 오래된 캡처 거부, 버튼 캡처로 인한 깜박임 방지, 실제 Tk/창 관리자 클릭과 기존 동작을 확인했습니다. Windows/MuMu 실기기 확인은 별도입니다.

이전 버전의 단축 시간 사전 탐색과 탐색성공 후 수동 실행, 통계창의 게임 포커스 연동, 개별 카드 ×N 집계·중복 방지를 유지합니다. 페이지 확인용 이미지는 자동으로 저장하지 않습니다.

적 콤보 조건 자동 인식, 파티/팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 이번 변경에 포함하지 않았습니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
