# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_26.zip)

프로그램을 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 개인 DB와 설정은 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.26: 짧은 이동시간에서 탐색 실패를 더 빨리 표시합니다. 이동시간 5초 이하는 탐색+비교 합계 최대 3초, 6~8초는 5초, 9초 이상은 기존 최대 10초입니다. 캡처/OCR 시간은 별도입니다.

이동 상한 안에서는 목표를 못 찾고 더 긴 비교 경로에서만 달성하면 요청한 문구 **제한시간부족**을 표시합니다. 비교도 같은 총예산 안에서 수행하며 상한을 넘는 경로는 자동 실행하지 않습니다. 시간 미확인·단순 경로 미발견·드롭 개수 부족은 구분합니다. [상세 안내](INVENTORY_PRECHECK.md#짧은-이동시간의-빠른-실패-안내-v10126)

검증: 회귀 237개. 실제 제공 실패 판은 5초 안전 이동 상한 기준 약 2.5초에 제한시간부족으로 분류했습니다. 실제 Tk/창 관리자에서 문구 표시/유지/판 변경 초기화, 기존 F7/경로 분리/결과 통계를 확인했습니다. Windows/MuMu 실기기 검증과는 구분합니다.

v101.25의 계산 버튼 포커스 시간 캡처 수정과 가림 검사, 오른쪽 마나 아래 결과 통계 및 개별 카드 ×N 집계를 유지합니다. 상단 ×2는 집계하지 않습니다.

적의 콤보 제한 자동 인식은 원본 PNG 검증 대기 중이며 이번 패치 미포함입니다. 파티/팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용도 아직 미적용입니다.

자동 이미지 저장은 하지 않습니다. 오류 저장/F12를 직접 누를 때만 진단 폴더를 만듭니다. 시간 캡처 성공 시 원본 게임 화면은 기존 한 판 RAM 캐시를 사용합니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
