# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_23.zip)

기존 프로그램을 종료하고 `시작.vbs`로 다시 실행하면 최신 버전을 확인합니다. 새 설치는 ZIP을 새 폴더에 압축 해제한 뒤 실행합니다. 설정과 개인 DB는 기존 LocalAppData/Pad0Overlay에서 읽으며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.23: **경로 계산 중 최소화된 크리스탈 창을 다시 펼치던 복원 코드를 수정했습니다.** F6/경로 계산은 F7 스캔을 호출하지 않습니다. 열린 관리창은 계산 시작 시 최소화하고, 이미 최소화된 창은 그대로 유지합니다. 캡처·계산·자동 이동 종료 후 관리창을 다시 띄우지 않습니다. [사용 안내](FARMING_STATS.md#경로-계산과-크리스탈-관리창-분리-보완-v10123)

F7로 직접 재료를 확인할 때는 관리창을 앞으로 표시합니다. 재료 이름 자동 등록은 최소화 상태에서 수행합니다. 전체 재료와 대상 이미지, 아텐 이름 및 이미지 연결을 유지합니다.

회귀 208개 및 실제 Tk/별도 창 관리자에서 정상/최소화 관리창 각각의 전체 경로 세션, 중첩 캡처, 관리창 deiconify/lift/F7 호출 없음 확인. Windows/MuMu 실제 화면 확인은 별도 필요합니다.

잠금·독·방해 드롭이 있던 실제 판의 버튼 미표시 원인은 아직 미확정입니다. 같은 상태에서 F12 수동 진단이 필요합니다. 진단에는 화면 확인 이유와 보드 판정, 안정화 횟수 및 후보 보드도 기록합니다. 자동 이미지 저장은 하지 않습니다.

수동 경로 조건 6종을 유지합니다. 파티와 팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 아직 미적용입니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
