# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_17.zip)

기존 프로그램을 종료하고 `시작.vbs`로 다시 실행하면 최신 버전을 확인합니다. 새 설치는 ZIP을 새 폴더에 압축 해제한 뒤 실행합니다. 설정과 개인 DB는 기존 LocalAppData/Pad0Overlay에서 읽으며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.17: 경로 조건을 **10콤보 · 다색팟(5속성) · 드롭8개 연결 · TPA · 십자팟 · L자팟**의 수동 선택 6종으로 정리했습니다. 각 항목에 설명을 표시하고 선택 조건을 실제 경로 검증과 연결했습니다. 모양 조건은 공격 5속성 중 하나로 검사하며, 같은 색 드롭이 추가로 붙은 모양은 제외합니다. 목표 미달 경로는 자동 실행하지 않습니다.

독 최소화 체크는 제거했습니다. 체력·회복량 기반 독 자동 판단, 파티와 팀 스킬 자동 인식, 저장 배치 34개를 이용한 경로 탐색은 이번 버전에 포함하지 않습니다. 기존 보수적인 독 위험 점수를 유지합니다. 패턴 원본 이미지도 공개 배포에 포함하지 않습니다.

회귀 테스트 181개, 실제 Tk 화면의 6종 선택·설정 저장·독 체크 제거를 확인했습니다. Windows/MuMu에서 실제 게임 스킬 발동은 별도 확인이 필요합니다. [경로 조건 안내](SOLVER_BENCHMARK.md#경로-조건-6종-v10117)

크리스탈은 돌파 화면 F7 → 게임 재료 클릭 → 상세 이름 자동 등록 흐름을 유지합니다. [사용 안내](FARMING_STATS.md#재료-클릭-후-이름-자동-등록-v10116)
자동 스크린샷 기록은 중단 상태를 유지하며 오류 저장 버튼 또는 수동 F12로만 진단 파일을 남깁니다.

다운로드 파일 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정을 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
