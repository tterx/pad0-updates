# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_30.zip)

프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 개인 DB와 설정은 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 **v101.30**: 5속성 모드에서 한 속성이라도 3개 미만이면 **콤보 우선 실행** 버튼을 표시합니다. 바인딩 여부와 관계없이 버튼/F6를 누르면 이번 실행만 콤보 우선으로 계산·실행합니다. 10콤보를 필수로 요구하지 않으며 최소 한 콤보를 검증합니다. 선택한 5속성 설정은 그대로 유지합니다. [사용 안내](INVENTORY_PRECHECK.md#5속성-수량-부족일-때-클릭으로-콤보-우선-실행-v10130)

판·가시·선택 조건·계산 경로가 같은 실행인지 재확인하고 완료/취소/F10/조건 변경/오류 시 임시 조건을 해제합니다. 이동시간 상한과 기존 독/가시 평가를 유지합니다. 수량이 충분하지만 경로를 못 찾은 경우나 다른 경로 조건은 자동 완화하지 않습니다. 수량 부족에서는 불필요한 단축 시간 사전 탐색/시간 OCR도 시작하지 않습니다.

이전에 요청한 대로 **재료확인 버튼을 흰색 제목 바 바깥 오른쪽**으로 옮겼습니다. 돌파 확인 화면에서만 표시하며 화면/창 전환 시 숨기는 동작은 유지합니다. [위치 변경 안내](FARMING_STATS.md#재료확인-버튼-위치-조정-v10130)

테스트 293개 통과. 첨부 배치 재현의 실제 콤보 탐색, 같은 실행에 한정된 조건 적용, 기존 목표 유지, 실제 Tk/창 관리자 버튼·예약·종료 후 조건 복구를 확인했습니다. Windows/MuMu 실기기 확인은 별도입니다.

이전 단축 시간 사전 탐색/수동 실행, 결과 통계의 게임 포커스 연동, 개별 카드 ×N 집계와 중복 방지를 유지합니다. 새 자동 이미지 기록은 추가하지 않았습니다.

적 콤보 무효 아이콘의 N+1 조건, 하단 콤보 가산 아이콘 자동 인식, 파티/팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 이번 변경에 포함하지 않았습니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
