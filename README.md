프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 **v101.159**를 확인합니다. 개인 DB와 설정은 유지합니다.

이번 버전은 두 번째 스테이지에서 시작 회복 드롭이 옆으로도 이동해 확인에 실패하던 문제를 수정합니다. 기존 무늬 기준으로 좌우 위치까지 찾고, 작은 커서 겹침에는 남아 있는 무늬를 더 강한 기준으로 확인합니다. 누른 상태의 시간 막대가 정지해도 드롭 자체로 확인합니다. [입력 확인 안내](INPUT_MODULE.md)

## 백그라운드 재료 파밍 — 첫 구현

잠입 확인 화면의 **파밍 설정**에서 등록된 돌파 대상과 재료를 선택·저장한 뒤 **재료 파밍** 버튼으로 시작합니다. 재료 목록이 없다면 돌파 확인 화면에서 F7/재료확인으로 먼저 등록합니다. 선택한 재료의 부족 수량이 모두 0이면 종료합니다. **F10** 또는 메인창에서 중지합니다. 선택은 재실행 후에도 유지되며 보상 통계창에서 다른 목표로 바뀌지 않습니다.

전투 중 화면과 연속 터치를 MuMu ADB로 처리하며 **자동 이동은 Windows 커서 이동·게임 창 전면 활성화를 사용하지 않습니다.** F10·정상 종료에서는 잔류 눌림 정리를 위해 Windows 마우스 UP과 MuMu 창 해제 메시지만 보냅니다. 다른 Windows 프로그램을 사용하면서 진행할 수 있는 구조입니다. MuMu 엔진은 실행 중이어야 하며 최소화/백그라운드 일시정지가 켜져 있으면 사용할 수 없습니다. 처음에는 **파밍 연결 설정 → 설정 마법사 시작**으로 설치 찾기→기기 연결→게임 화면 확인→저장을 순서대로 진행하세요. ADB는 `MuMuPlayer/nx_device/설치버전/shell/adb.exe`를 우선 찾습니다. 이전 경로가 저장돼 있다면 마법사의 **자동으로 찾기**를 다시 누르세요. offline 상태를 표시하고 재연결을 도우며, MuMu 자체의 ADB 허용은 필요한 경우 직접 켜야 합니다. 공식 사이트 버튼은 제거했습니다. 마법사 안의 **그림으로 보는 ADB·포트 설정**은 사용자가 공유한 참고 글을 엽니다. MuMu 설정에 5555,16384가 함께 표시되면 두 포트를 확인할 수 있으며, 목록에 없는 포트는 주소를 직접 입력해 연결할 수 있습니다. 내장 **경로 설정 방법**은 파일·기기 주소·offline 해결 순서를 보여줍니다. 연결을 못 찾으면 메인창 **파밍 연결 설정**에서 MuMu의 `shell/adb.exe`와 기기 주소를 지정합니다.

**파티 설정**은 클릭 시 앞으로 표시됩니다. **현재 파티 전체 읽기**는 상세를 4.2초 눌러 한 번 열고 화살표로 순회하며 한 명씩 저장합니다. 실패한 4번만 선택해 **선택한 슬롯만 읽기**로 보완할 수 있습니다. 이미 열린 상세에서도 선택 슬롯 기준으로 읽을 수 있습니다. 번호·레벨·스킬·각성을 확인하고 정정할 수 있습니다. 공개 상세에서 확인한 몬스터 510종의 일본어 DB를 내장하고, 게임의 한글 이름 및 사용자 정정을 보존합니다. 잠금·속성 부족·시간 감소·상태이상·콤보 제한에 맞춰 스킬을 선택합니다. 무효 방패/공격력 감소처럼 그림만 보이는 상태는 아이콘을 먼저 등록해야 대응할 수 있습니다. 목표 재료를 모두 채우면 바탕화면 완료 알림을 표시합니다.

회귀 **408개** 통과. 모의 게임의 2회 누적→목표 종료, 집계 실패/다른 스테이지 차단, 실제 별도 프로세스의 모의 ADB 캡처/연속 입력/취소, 실제 OCR의 재현 한국어 화면과 실제 Tk 버튼 위치·숨김을 확인했습니다. **Windows/MuMu가 이 환경에 연결돼 있지 않아 실제 상세창·게임 터치·최소화·전체 클리어는 실기기 검증 전입니다.**
