# 퍼드0 올인원 1.0.18

[프로그램 ZIP 다운로드](https://github.com/tterx/pad0-updates/releases/download/v1.0.18/pad0_overlay_windows_v1_0_18.zip)

기존 설치는 PAD0를 완전히 종료한 뒤 `시작.vbs`를 다시 실행하면 업데이트됩니다. 새 설치는 ZIP을 풀고 `시작.vbs`를 실행하세요. 표시 버전은 **1.0.18**, 자동 업데이트 내부 순번은 **226**입니다.

바인드·각성무효 해제 → 필요한 잠금 해제·5속성 생성 → 구름 확인 순서로 진행합니다. 칼리처럼 해제와 생성을 함께 하는 스킬은 중복 생성하지 않습니다. 구름 확인 후 실제 속성이 부족하면 다음 생성 스킬을 쓰고 다시 확인합니다. 체력이 낮아도 5속성·6콤보가 우선이며 회복은 가능한 경우 포함합니다.

구름의 들린 독 드롭을 개발환경에서 학습한 보조 모델로 판독합니다. 판독하지 못한 구름 칸은 임시 방해(J)로 계산을 계속하며, 임시값을 학습 정답이나 확정 관측으로 저장하지 않습니다.

앱은 개발환경에서 학습해 배포한 내장 모델만 사용합니다. 로컬 학습·자료 저장·모델 업로드 기능은 제거됐습니다. 업데이트 후 첫 실행에 사용자 데이터의 `ai_review/`(모델·원본·정답·전송 대기 자료), `ai_quantities/`, `board_history.json`을 삭제합니다. 크리스탈 DB·재고·파티·이동 속도·일반 설정과 사용자가 저장한 오류 ZIP은 유지합니다. 삭제 실패는 AI 모델 상태에 표시하고 다음 실행에 다시 시도합니다.

최종 소스의 Windows 집중 검사196개 통과. Linux 전체233개 중232개 통과, Windows 전용1개 건너뜀, 실패·오류0개. ZIP 무결성·번들 로딩·업데이트·이전 파일 백업·재실행·손상 파일 차단·AI 자료 정리를 검증했습니다. 실제 MuMu 게임 조작은 이번 환경에서 검증하지 않았습니다. 독 모델 학습 표본은 작으며 실제 전체 인식률을 뜻하지 않습니다.
