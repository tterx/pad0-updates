# PAD0 개인용 업데이트 배포

Windows/MuMu용 PAD0 프로그램의 실행 패키지와 자동 업데이트 파일입니다.

[최신 실행 패키지 다운로드](https://github.com/tterx/pad0-updates/releases/latest/download/pad0_overlay_windows_v101_1.zip)

프로그램을 종료하고 ZIP을 새 폴더에 압축 해제한 뒤 `시작.vbs`로 실행합니다. 이후 실행할 때 최신 버전을 확인합니다.
개인 DB와 설정은 기존 LocalAppData/Pad0Overlay에 보관하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://github.com/tterx/pad0-updates/releases/latest/download/update.json

현재 v101.1: 5속성 탐색 최대 10초, 조건 충족 즉시 반환, 목표 미달 실행 차단, 크리스탈 수동 계산.
실패판 23개 중 8개 성공한 제한적 실험 결과이며, Windows/MuMu 실기기 동작 검증이 필요합니다.

이 저장소와 배포 파일은 공개되어 있습니다.
