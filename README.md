# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_22.zip)

기존 프로그램을 종료하고 `시작.vbs`로 다시 실행하면 최신 버전을 확인합니다. 새 설치는 ZIP을 새 폴더에 압축 해제한 뒤 실행합니다. 설정과 개인 DB는 기존 LocalAppData/Pad0Overlay에서 읽으며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.22: **F7로 직접 재료를 읽으면 관리창을 게임 앞으로 표시하고, 이후 재료 이름 자동 등록은 관리창을 최소화한 상태로 처리합니다.** 창 숨김 대신 최소화를 사용하므로 사용자가 직접 다시 복원할 수 있습니다. 자동 등록 완료 후에는 앞으로 다시 띄우지 않습니다.

F7의 전면 확인을 위해 일시적으로 앞으로 올리되, 게임 등 다른 창으로 돌아가면 해제합니다. 고정 설정은 계속 켜 두지 않습니다. 전체 5개 재료 목록과 수량, 돌파 대상 이미지, 기존 아텐 이름과 이미지 연결을 유지합니다. [사용 안내](FARMING_STATS.md#f7-전면-확인과-이후-최소화-구분-v10122)

회귀 204개 및 실제 Tk/별도 창 관리자에서 F7 전면 표시 요청·iconify 최소화·최소화 후 아텐 등록·숨김 및 자동 재표시 없음·수동 재열기를 검증했습니다. Windows/MuMu 실제 전면 표시와 작업표시줄 복원은 별도 확인이 필요합니다.

수동 경로 조건 6종을 유지합니다. 파티와 팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 아직 미적용입니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
