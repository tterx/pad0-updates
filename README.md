# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_27.zip)

프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 개인 DB와 설정은 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.27: 첨부 원본에서 시간 ‘13’과 배경 ‘4’를 함께 읽어 미확인/23회 상한을 적용하던 문제를 수정했습니다. 흰색 시간 배지 숫자만 직접 두 번 읽고 일치 확인하며 배지 밖 숫자는 제외합니다. 광원 때문에 물로 읽힌 방해 드롭 2개와 잘못된 가시 표시도 보완했습니다. 실제 원본+한국어 OCR+탐색으로 13초 기준 50회 이동의 5속성 경로를 확인했습니다. [경로 수정 안내](INVENTORY_PRECHECK.md#첨부-원본의-13초-숫자-혼입과-방해-드롭-수정-v10127)

보상 집계에는 고유한 카드 그림 띠를 대조하는 스크롤 보조 측정과 프레임 안정화 재시도를 추가했습니다. F7 없이 재실행해도 기존 DB로 시작합니다. 결과창을 나간 뒤에는 복원 휠도 보내지 않습니다. 상단 ×2 제외와 개별 카드 ×N 집계/중복 방지를 유지합니다. [보상 집계 안내](FARMING_STATS.md#f7-없이-재실행과-스크롤-대조-보완-v10127)

회귀 247개 통과. 실제 원본의 13초/5초 숫자, 방해/물 구분, 합성 양방향 스크롤·빈/반복 그림 거부·F7 없는 재실행·결과 종료 입력 차단, 실제 Tk/창 관리자 기존 동작 확인. Windows/MuMu 실기기와 실제 실패 보상 목록 검증은 별도입니다.

짧은 이동시간의 빠른 탐색과 ‘제한시간부족’ 안내, 결과 통계의 마나 아래 오른쪽 표시, F7/경로 계산 창 분리는 유지합니다. 자동 이미지 저장은 없으며 오류 저장/F12를 직접 누를 때만 파일을 만듭니다.

적 콤보 조건 자동 인식은 원본 PNG 검증 대기로 아직 미적용입니다. 이번 적 원본은 방패 75이며 6/7/8 콤보 아이콘 원본이 필요합니다. 파티/팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용도 아직 미적용입니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
