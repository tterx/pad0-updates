# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_32.zip)

프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 개인 DB와 설정은 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 **v101.32**: 사전 탐색은 휴식/시작을 포함한 대기 최대 약 10초에서 멈춥니다. 자식 프로세스 자체 제한과 부모 감시 타이머를 함께 사용합니다. 같은 판·조건·시간에서 자동으로 무한 재시작하지 않습니다.

수량이 충분한 5속성 경로를 한도 안에 못 찾으면 **시간부족(탐색 한도) · 콤보로 실행**을 표시합니다. 직접 계산 실패 후에도 제공합니다. 다음 버튼 클릭에서만 새 판·가시·조건·시간을 확인하고 이번 실행을 콤보로 전환합니다. 5속성 설정은 유지하며 자동으로 이동하지 않습니다. Shift+F6는 원래 조건 재탐색입니다. ‘시간부족’은 탐색 한도 안내이며 게임 이동시간이 실제로 모자란다는 확정은 아닙니다. [탐색 안내](INVENTORY_PRECHECK.md#사전-탐색-대기-한도와-콤보-전환-v10132)

**연전 확인 화면**에도 필요·이번·보유·부족 통계창을 표시합니다. 저장된 수량만 보여주고 보상을 재집계하지 않습니다. 현재 실행에서 F7을 거치지 않았어도 기존 프로필로 표시하며, OK/그만두기 클릭이나 화면/판 전환 시 숨깁니다. 다른 앱 전환 시 상단 고정 해제도 유지합니다. [통계 안내](FARMING_STATS.md#연전-확인에서-재료-통계-표시-v10132)

테스트 310개 통과. 실제 별도 프로세스 만료와 부모 종료 검사, 실제 Tk/창 관리자 표시·숨김, 재현 화면의 한국어 연전 제목 OCR을 확인했습니다. 첨부 10초 실패 판의 다음 클릭을 콤보로 전환해 44회 이동·6콤보 경로와 실행 검증을 확인했습니다. Windows/MuMu 실기기 검증은 별도입니다.

수량 부족 판의 콤보 전환, 사전 탐색 중 수량 안내, 기존 이동시간 상한·마우스 개입 차단·결과 중복 집계 방지를 유지합니다. 새로운 자동 이미지 기록은 추가하지 않았습니다.

적 콤보 무효 아이콘의 N+1 조건, 하단 콤보 가산 아이콘 자동 인식, 파티/팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 이번 변경에 포함하지 않았습니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
