# 퍼드0 올인원 1.0.13

[프로그램 ZIP 다운로드](https://github.com/tterx/pad0-updates/releases/download/v1.0.13/pad0_overlay_windows_v1_0_13.zip)

기존 설치는 PAD0를 완전히 종료한 뒤 `시작.vbs`를 다시 실행하면 업데이트됩니다. 새 설치는 ZIP을 풀고 실행하세요. 표시 버전은 **1.0.13**, 자동 업데이트의 내부 순번은 **221**입니다. v1.0에서도 정상적으로 업데이트할 수 있습니다.

097의 한 칸 구름에서 회색 턴수 표시가 흰 구름 중심을 가려 구름 감지가 빠지던 문제를 보완했습니다. 해당 칸을 방해 드롭으로 확정하지 않고 기존 구름 기억·제자리 확인 절차로 보내며, 확인된30칸으로만 계산합니다.

회색 중앙 사각형·안쪽 빨간 글자·바깥쪽 흰 구름 테두리가 함께 있어야 추가 감지합니다. 턴수 숫자를 드롭 색으로 읽거나 가려진 색을 추측하지 않습니다. 실제097 이동 전후 이미지와 두 배율을 검사했고, 흰 테두리나 빨간 글자가 없으면 추가 감지를 거부합니다. 기존 잘못 읽은 판의 눈에 보이는 불일치는 여전히 거부합니다.

1.0.3에서 별도 학습해 내장한 방해/물 전용 보조 모델을 유지합니다. 실제 드롭122개를 원본 화면 그룹별로 학습73개·선택 검증36개·마지막085 평가13개로 나눴습니다. 학습 자료에만 변형을 추가해584개 입력을 만들고320epoch×초기값3개(총960번 갱신)를 수행했습니다. 검증36개와 미학습085의13개는 모두 맞았으며, 작은 같은 게임 자료의 결과로 실사용 전체 정확도를 의미하지 않습니다. 확신/거리/무늬/파란색 조건이 부족하면 기존 판독을 유지합니다. 기존 사용자 일반AI 파일은 보존하며 별도 학습UI는 추가하지 않았습니다. [학습 기록](JAMMER_WATER211.json).

조작은 **MuMu SDK**, 스킬 클릭은 **기존 컨트롤러**, 화면은 **MuMu 강화 캡처**로 고정합니다. 방식 선택 메뉴는 제거했습니다. **매칭 속도 조절**의 이동 간격10~40ms와 코너 추가 대기0~80ms는 유지하며 저장된 SDK 속도·ADB 경로·개인 DB·학습 모델을 보존합니다.

재료확인(F7)으로 재료를 등록하고 크리스탈 관리에서 파밍할 재료를 선택하세요. 보상 집계 후 **연전 확인**에서 선택 재료가 부족하면 **OK**로 계속합니다. 모두 모으면 **그만두기** 입력 완료 즉시 복귀 화면을 기다리지 않고 작은 완료음과 팝업을 표시합니다. 팝업에는 선택한 재료별 총 보유 수량과 이번 자동파밍에서 획득한 마나를 표시하며, 알림은 한 번만 나옵니다. 알림 설정은 크리스탈 관리에서 변경할 수 있습니다. 버튼의 실제 영역과 글자를 확인하며 OK 아래의 소모량을 글자 판독에서 제외합니다. 불확실한 클릭을 반복하지 않습니다.

부족한 속성/회복을 보완할 준비된 스킬을 먼저 확인하고, 보완할 스킬이 없으면 현재 판에서 가능한 회복·콤보 경로로 진행합니다. 보상 수량·스킬 발동·실제 퍼즐 이동이 확인되지 않으면 오류 ZIP을 남기고 안전하게 중지합니다. **F10**으로 중지할 수 있고, 중지 후 파밍 연결 설정도 다시 열 수 있습니다. MuMu 엔진은 실행 중이어야 합니다.

Linux 핵심·관련361개, Windows154개 및 패키징 검사를 통과했습니다. 사용자 MuMu 실기는 미확인입니다. [변경 및 검증 범위](REVIEW221.md) · [검사 결과](release_checks221.json).

학습은 학습→학습데이터 정리→학습된 모델 업로드 순서입니다. 개인 원본 학습 이미지는 이 공개 프로그램 저장소에 업로드하지 않습니다.
