# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_25.zip)

기존 프로그램을 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 설정과 개인 DB는 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.25: 계산 버튼이 포커스를 가진 정상 상황을 ‘게임이 전면에 없음’으로 거부하던 시간 캡처를 수정했습니다. 경로 전용 캡처는 게임/메인창/계산 버튼에 포커스가 있고 시간 영역·보드가 실제 게임으로 보일 때만 허용합니다. 다른 앱 전면, 가림, 최소화는 계속 차단합니다. 보상 감시의 전면 조건은 유지합니다.

목표 미달 시 버튼에 **다시 계산 · 경로 미발견**, 5속성 조건에서는 **5속성 경로 미발견 4/5 · 이동 안 함**처럼 결과를 유지합니다. 목표 미달 경로는 자동 실행하지 않습니다. 판/조건 변경이나 재계산 시 안내를 초기화합니다. [수정과 검증 안내](INVENTORY_PRECHECK.md#경로-버튼-포커스와-목표-미달-안내-v10125)

회귀 230개 통과. Windows API 모의 포커스/가림 검사, 제공된 두 보드의 10초/13초 기준 40회/46회 이동 5속성 탐색, 실제 Tk/창 관리자에서 안내 유지/초기화 및 기존 F7/경로 분리/결과 통계를 확인했습니다. Windows/MuMu 실기기 성공 여부와는 구분합니다.

결과 통계는 오른쪽 마나 아래에 첫 결과 화면부터 표시하고 유지합니다. 등록 재료 그림과 일치 카드 아래 ×N만 더하며 상단 ×2는 무시합니다. [결과 통계 안내](FARMING_STATS.md#결과-통계-표시와-인식-보완-v10124)

자동 이미지 저장은 하지 않습니다. 시간 캡처 성공 시 계산 시점 게임 원본을 기존 한 판 RAM 캐시에 보관하여 오류 저장을 누를 때만 저장합니다. F12 수동 진단도 유지합니다.

F7 직접 확인 시 관리창 전면 표시, 자동 이름 등록 및 경로 계산 중에는 관리창 최소화를 유지합니다. 수동 경로 조건 6종을 유지하며 파티와 팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 아직 미적용입니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
