# 퍼드0 올인원 1.0.32

[프로그램 ZIP 다운로드](https://github.com/tterx/pad0-updates/releases/download/v1.0.33/pad0_overlay_windows_v1_0_33.zip)

정상9초 판에서도 **TPA 경로를 미리 탐색**하고 준비 후 **경로 실행**을 누르면 저장된 경로를 재확인해 실행합니다. 클릭 전 게임 입력은 없습니다. 수동 이동은 칸당75ms 목표로 조정하고 자동 파밍 속도는 유지합니다. [변경·검증](REVIEW235.md).

EX1 등 EX 스테이지 번호를 등록하고 긴 출현 크리스탈 목록의 아래 끝까지 확인합니다. 스크롤이 정체되면 완료로 저장하지 않습니다. [변경·검증](REVIEW236.md).

TPA 미발견 판을 자동 재탐색하고 수동 구름의 미확인 칸을 임시 방해로 계산합니다. 적 콤보 무시 조건은 TPA에도 필수로 확인합니다. [변경·검증](REVIEW237.md).

1TPA 이상+최종6콤보를 최우선으로 찾고6콤보를 유지할 때2TPA·3TPA로 개선합니다. 첫 유효 경로부터 실행할 수 있습니다. [변경·검증](REVIEW238.md).

TPA+6콤보를 배열로 동시 탐색하고, 시간·가산 값이 갱신되면 저장 경로를 현재 조건으로 다시 검증합니다. 초기 TPA 사전 탐색에서는 체력 OCR을 미룹니다. [변경·검증](REVIEW239.md).

플레이 후 직접 선택한 경로 조건을 유지·저장하며 TPA 자동 설정으로 덮어쓰지 않습니다. 지우기&콤보를 선택하면1TPA+최종6콤보 우선을 적용합니다.

작은 빨간 수량이 확대 영상에서 글자로 오인되면32/24px로 재확인합니다. 두 판독 일치와 자릿수·잘림·범위 검사는 유지합니다. [변경·검증](REVIEW240.md).

주황 카드 테두리를 빨간 수량 획에서 제외해 보유×1 판독을 보완했습니다. 실제 잘림·×누락은 차단하며 보유 수량 오류의 상세 이유를 표시합니다. [변경·검증](REVIEW241.md).

기존 설치는 PAD0를 완전히 종료한 뒤 `시작.vbs`를 다시 실행하면 업데이트됩니다. 새 설치는 ZIP을 풀고 `시작.vbs`를 실행하세요. 표시 버전은 **1.0.32**, 자동 업데이트 내부 순번은 **241**입니다.

보고된 어둠4개·9초 판에서 4매치를 먼저 확보하는 전용 탐색을 추가했습니다. 실제8이동 경로를 확인하고, 확보한 TPA를 보존하며 선택적 콤보 탐색을 이어갑니다. 원본 이미지 인식 및 실기 검증은 별개입니다. [변경·검증](REVIEW234.md) · [전사한 판](TPA234.json).

수동 계산에서도1TPA 이상과 최종6콤보를 먼저 확보하고, 이를 유지하면서4매치 개수를 늘립니다. 상태창에 1TPA·2TPA·3TPA·4TPA를 표시하고, 하나도 못 찾으면 속성부족을 표시합니다. 같은 판의 결과 표시를 유지합니다. [변경·검증](REVIEW233.md).

TPA 보유 파티는 해당 속성의 정확한4개 매치와 최종6콤보를 함께 만족해야 실행합니다. 2TPA·3TPA는 이 조건을 유지하는 차선 개선입니다. 드롭 생성 택틱과 관측 쿨타임에 대한 턴 단축, 지운 가산 드롭의 개수별 합산을 추가했습니다. 가산 아이콘 모델은 원본108의 실제 아이콘1개와 렌더링 표본으로 개발환경에서 보완한 고정 모델입니다. 최신 inline 스샷의 원본 픽셀 인식은 미검증입니다. [변경·검증 범위](REVIEW232.md).

재료확인의 흰색·빨간색 필요 수량 **1~999**와 보유 수량 **×0~999**를 같은 절차로 읽고 등록합니다. 세 자리 잘림과 빨간 보유0 거부 경로를 제거하고, 작은 ×·붙은111·작은0 판독을 보완했습니다. 출현 재료 미리보기에도 적용합니다. 개인 수량 템플릿의 사용·저장을 제거하며 과거 파일만 정리합니다. [변경 근거](REVIEW231.md) · [실제 OCR 검증](QUANTITY231.json).

메인창의 크리처 1기 등록·등록한 크리처/각성 확인 버튼을 제거하고 **스킬 택틱 · 상태별 우선순위** 창을 추가했습니다. 현재 파티 6기의 스킬을 보면서 상태별 사용 순서를 편집·저장합니다. 준비된 대응 스킬 사이에서 저장한 순서를 따르며, 파티가 바뀌면 다른 캐릭터에게 이전 순서를 적용하지 않습니다. 저장한 택틱은 다음 자동 파밍부터 적용합니다.

각성 등록은 등록 전후의 크리처 번호를 확인해 연결합니다. 이름 OCR이 흔들려도 동일 번호의 각성 이름·효과를 두 번 확인하면 등록할 수 있으며, 기존 이름을 잘못 읽은 이름으로 덮어쓰지 않습니다. 번호가 달라지거나 각성 설명이 일치하지 않으면 저장하지 않습니다.

팀 조건은 **지우기&콤보**입니다. TPA 파티는 해당 속성의 정확한4개 매치와 최종6콤보를 함께 확보합니다. TPA가 없는 일반 지우기&콤보에서는4개 이상 연결·6콤보·2초 여유를 확인합니다. 실제 지운 가산 드롭만 콤보에 더하고, 확률로 새로 출현할 드롭은 미리 더하지 않습니다.

**TPA**는 파티에서 TPA 각성을 가진 캐릭터의 주·부속성만 정확한 4개 매치 목표에 포함합니다. 다른 속성의 4개 매치로 목표를 충족했다고 처리하지 않습니다. [변경·검증 근거](REVIEW230.md).

전체 바인드로 사용할 대응 스킬이 없거나 적의 판 변환으로 5속성 공격이 불가능하면 **판 정리**로 턴을 진행합니다. 자동·수동 모두 콤보 조건 없이 지우는 드롭 수가 우선입니다. 자동은 매치가 없어도 실제 한 칸을 움직이고, 수동은 매치를 확인한 정리 경로를 실행합니다. 사용 가능한 해제·생성 스킬과 정상 공격 판의 5속성 우선 순서는 유지합니다. [변경·검증 근거](REVIEW229.md) · [옮긴 판의 경로 재현](BOARD_CLEAR229.json).

가시가 붙은 어둠 드롭을 잡았을 때 중앙이 독처럼 읽혀 자동 이동 전에 멈추던 문제를 수정했습니다. 실제 들린 무늬·가시·배경으로 잡힌 상태를 확인합니다. 수동 경로도 표시상의 가시 정보만 달라지고 실제 위험 조건은 같으면 실행할 수 있게 했습니다. 체력 저하·새로운 위험·실제 드롭 변경은 계속 확인합니다. [원인과 수정 근거](REVIEW228.md) · [첨부104 재현 결과](THORN_START228.json).

시간 숫자 배지가 흰 판 테두리에 붙어도 오른쪽 숫자 윤곽으로 찾아 읽고 왼쪽 시계는 제외합니다. 첨부103의 실제8초를 두 OCR 판독에서 확인했습니다(99.08%,91.96%). 판독 충돌·가림은 추측하지 않습니다.

시간을 읽지 못하거나 대응 가능한 스킬·기존 경로가 없으면4초 잔여 조건을 해제하고 **5속성·6콤보 → 6콤보만** 순서로 시도합니다. 정상적으로 기존 조건을 만족하는 경로는 유지합니다. 시간 미확인 시의5초는 제한된 입력 예산이며 실제 인식값이 아닙니다. AI 모델 버튼도 제거했습니다. [시간 인식·단계별 경로 검증](REVIEW227.md) · [실제 OCR 결과](TIMER_OCR227.json).

바인드·각성무효 해제 → 필요한 잠금 해제·5속성 생성 → 구름 확인 순서로 진행합니다. 칼리처럼 해제와 생성을 함께 하는 스킬은 중복 생성하지 않습니다. 구름 확인 후 실제 속성이 부족하면 다음 생성 스킬을 쓰고 다시 확인합니다. 체력이 낮아도 5속성·6콤보가 우선이며 회복은 가능한 경우 포함합니다.

구름의 들린 독 드롭을 개발환경에서 학습한 보조 모델로 판독합니다. 판독하지 못한 구름 칸은 임시 방해(J)로 계산을 계속하며, 임시값을 학습 정답이나 확정 관측으로 저장하지 않습니다.

앱은 개발환경에서 학습해 배포한 내장 모델만 사용합니다. 로컬 학습·자료 저장·모델 업로드 기능은 제거됐습니다. 업데이트 후 첫 실행에 사용자 데이터의 `ai_review/`(모델·원본·정답·전송 대기 자료), `ai_quantities/`, `board_history.json`을 삭제합니다. 크리스탈 DB·재고·파티·이동 속도·일반 설정과 사용자가 저장한 오류 ZIP은 유지합니다. 삭제 실패는 AI 모델 상태에 표시하고 다음 실행에 다시 시도합니다.

렌더링한 수량4,564건의 실제 OCR와 두 재료 패널 등록 검사 통과. 원본 첨부 이미지 픽셀 OCR은 미검증입니다. 최종 소스의 Windows 집중 검사375개 통과. Linux 전체412개 중411개 통과, Windows 전용1개 건너뜀, 실패·오류0개. ZIP 무결성·번들 로딩·업데이트·이전 파일 백업·재실행·손상 파일 차단·AI 자료 정리를 검증했습니다. 실제 MuMu 게임 조작은 이번 환경에서 검증하지 않았습니다. 독 모델 학습 표본은 작으며 실제 전체 인식률을 뜻하지 않습니다.
