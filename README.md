# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_19.zip)

기존 프로그램을 종료하고 `시작.vbs`로 다시 실행하면 최신 버전을 확인합니다. 새 설치는 ZIP을 새 폴더에 압축 해제한 뒤 실행합니다. 설정과 개인 DB는 기존 LocalAppData/Pad0Overlay에서 읽으며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.19: 제공된 실제 OCR 결과 ‘아텐의크리스탈’(.99795) / ‘아텐외 크리스탈’(.91808)의 불일치로 이름 등록이 막히던 문제를 보완했습니다. 등록된 캐릭터 이름과 접미어가 정확하고 의/외 조사만 다를 때, 올바른 의 판독 신뢰도 .97 이상 및 보조 판독 .85 이상을 요구합니다. 이름 글자를 임의 보정하지 않습니다.

**상세 제목은 아텐의 크리스탈로 확인하고, 재료 목록과 DB 이름은 아텐으로 저장합니다.** 이름만 있는 기존 아텐 항목에 현재 재료 이미지를 붙여 기존 ID를 재사용합니다. 돌파 대상도 아텐이면 같은 이미지와 재료 ID를 연결하고 다음 F7에서도 유지합니다. 기존 이미지와 수량, 관리창 고정 상태를 보존합니다. [사용 안내](FARMING_STATS.md#이름만-저장한-항목에-이미지-연결-v10119)

돌파 화면에서 F7로 대상과 재료를 읽고, 게임에서 재료를 클릭한 뒤 상세창을 유지합니다. 상세창에서 F7을 다시 누를 필요가 없습니다. 클릭 신호 누락과 제목 위치 변경에 대한 v101.18 보완도 유지합니다.

회귀 테스트 199개, 실제 Tk에서 제공된 OCR 판독 쌍으로 기존 이름만 있는 아텐 항목의 이미지 연결·이름 갱신·필요7/보유2·고정 꺼짐 유지·중복 없음 검증을 통과했습니다. Windows/MuMu 실기기에서 최종 동작은 별도 확인이 필요합니다.

수동 경로 조건 6종을 유지합니다. 파티와 팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 아직 미적용입니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
