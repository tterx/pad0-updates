# PAD0 개인용 업데이트 배포

[최신 ZIP 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_204.zip)

**v101.204**: 잠금 해제 스킬은 경로 탐색 전에 판단합니다. Android 표준 스킬 클릭은 같은 좌표를80ms 유지하는 한 명령으로 보강했고 발동 근거가 없으면 재사용하지 않고 중단합니다. 070의 실제 실패 원인과 이 변경의 실기 성공은 아직 확정할 수 없습니다.

**현재 v202/v203 app 설치는 ZIP을 다시 받을 필요 없이, 완전히 종료하고 시작.vbs로 실행하면 일반 업데이트로 폴더 정리까지 적용됩니다.** 검증된 번들 안에 실행기/보조 파일/사용법을 함께 넣어 적용합니다. 기존 업데이트 주소 설정은 보존합니다. 오래된 평면 설치나 새 설치만 ZIP 전체를 사용하세요.

`디버그 폴더 열기.bat`는 최상단으로 옮겼습니다. 폴더 먼저/실행 파일 아래 표시는 탐색기의 **정렬 → 이름 → 오름차순**으로 선택하세요. 사용자 보기 설정/레지스트리를 자동으로 바꾸지 않습니다. ZIP에는 MD·별도 카탈로그·개발 도구를 넣지 않습니다.

새 archive는 만들지 않고, 알려진 이전 파일과 기존 archive/legacy-root-* 안의 알려진 파일만 정리합니다. 모르는 파일·개인 DB·설정·학습 모델·ADB는 유지합니다. 저장된17ms·코너0 등 이동 속도도 유지합니다.

F10 후 입력 정리 대기 중에도 **파밍 설정**에서 로컬 목표를 편집할 수 있습니다. 자동입력 재시작은 기존 정리가 끝나야 합니다. 창은 앞으로 복원하며 설정 열기가 중지 상태를 해제하지 않습니다.

[070 근거·변경·실기 확인 범위](REVIEW204.md). 첨부 분석·정적 구문·번들/부수 파일·원격 정합성만 확인했으며 자동검사/속도시험/시뮬레이션/에뮬레이터 조작은 실행하지 않았습니다.

## 백그라운드 재료 파밍 — 첫 구현

잠입 확인 화면의 **파밍 설정**에서 등록된 돌파 대상과 재료를 선택·저장한 뒤 **재료 파밍** 버튼으로 시작합니다. 재료 목록이 없다면 돌파 확인 화면에서 F7/재료확인으로 먼저 등록합니다. 선택한 재료의 부족 수량이 모두 0이면 종료합니다. **F10** 또는 메인창에서 중지합니다. 선택은 재실행 후에도 유지되며 보상 통계창에서 다른 목표로 바뀌지 않습니다.

전투 중 화면과 입력은 연결 설정에 따른 MAA/MuMu/scrcpy/Android 방식으로 처리하며 **자동 첫 퍼즐 시작 전 커서가 실제 퍼즐판 위에 있을 때만 판 밖으로 한 번 옮기며, 경로 이동은 선택한 컨트롤러로 연속 처리합니다. 게임 창을 전면 활성화하지 않습니다.** F10·정상 종료에서는 잔류 눌림 정리를 위해 Windows 마우스 UP과 MuMu 창 해제 메시지만 보냅니다. 다른 Windows 프로그램을 사용하면서 진행할 수 있는 구조입니다. MuMu 엔진은 실행 중이어야 하며 최소화/백그라운드 일시정지가 켜져 있으면 사용할 수 없습니다. 처음에는 **파밍 연결 설정 → 설정 마법사 시작**으로 설치 찾기→기기 연결→게임 화면 확인→저장을 순서대로 진행하세요. ADB는 `MuMuPlayer/nx_device/설치버전/shell/adb.exe`를 우선 찾습니다. 이전 경로가 저장돼 있다면 마법사의 **자동으로 찾기**를 다시 누르세요. offline 상태를 표시하고 재연결을 도우며, MuMu 자체의 ADB 허용은 필요한 경우 직접 켜야 합니다. 공식 사이트 버튼은 제거했습니다. 마법사 안의 **그림으로 보는 ADB·포트 설정**은 사용자가 공유한 참고 글을 엽니다. MuMu 설정에 5555,16384가 함께 표시되면 두 포트를 확인할 수 있으며, 목록에 없는 포트는 주소를 직접 입력해 연결할 수 있습니다. 내장 **경로 설정 방법**은 파일·기기 주소·offline 해결 순서를 보여줍니다. 연결을 못 찾으면 메인창 **파밍 연결 설정**에서 MuMu의 `shell/adb.exe`와 기기 주소를 지정합니다.

**파티 설정**은 클릭 시 앞으로 표시됩니다. **현재 파티 전체 읽기**는 상세를 4.2초 눌러 한 번 열고 화살표로 순회하며 한 명씩 저장합니다. 실패한 4번만 선택해 **선택한 슬롯만 읽기**로 보완할 수 있습니다. 이미 열린 상세에서도 선택 슬롯 기준으로 읽을 수 있습니다. 번호·레벨·스킬·각성을 확인하고 정정할 수 있습니다. 공개 상세에서 확인한 몬스터 510종의 일본어 DB를 내장하고, 게임의 한글 이름 및 사용자 정정을 보존합니다. 잠금·속성 부족·시간 감소·상태이상·콤보 제한에 맞춰 스킬을 선택합니다. 무효화 방패와 속성 흡수는 내장 아이콘으로도 확인하며, 내장 판독이 없는 효과는 아이콘을 먼저 등록해야 대응할 수 있습니다. 목표 재료를 모두 채우면 바탕화면 완료 알림을 표시합니다.

정적 검토와 실기 확인 범위는 [REVIEW201.md](REVIEW201.md)에 기록합니다. 실제 Windows/MuMu 전체 클리어는 실기 확인 전입니다.
