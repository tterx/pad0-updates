# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_18.zip)

기존 프로그램을 종료하고 `시작.vbs`로 다시 실행하면 최신 버전을 확인합니다. 새 설치는 ZIP을 새 폴더에 압축 해제한 뒤 실행합니다. 설정과 개인 DB는 기존 LocalAppData/Pad0Overlay에서 읽으며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.18: **돌파 화면 F7 → 게임에서 재료 클릭 → 상세 이름 자동 등록** 흐름에서 클릭 신호가 누락되는 경우를 보완했습니다. 게임 상단 제목줄이 바뀌는 것을 두 번 확인하면 이름 판독을 시작하고, 고정된 예전 제목 좌표 대신 현재 제목줄 위치를 찾습니다. 상세창에서 F7을 다시 누를 필요가 없습니다.

클릭 기록 없는 자동 연결은 최근 F7의 단일 재료와 동일한 돌파 대상 이름을 명시적인 상세 제목에서 확인한 경우로 제한합니다. 여러 재료를 임의 연결하지 않습니다. 기존 이미지·ID·필요/보유 수량·돌파 대상·관리창 고정 상태를 유지합니다. 같은 화면에서 OCR을 반복하지 않으며 주기적인 이미지 파일도 저장하지 않습니다. [사용 안내](FARMING_STATS.md#클릭-신호-누락과-상세-제목-위치-변경-보완-v10118)

회귀 테스트 190개, 실제 Tk에서 클릭 신호를 보내지 않고 상세 제목 위치를 옮긴 경우의 아텐 자동 등록·필요7/보유2·고정 꺼짐 유지·중복 없음 검증을 통과했습니다. 실제 한국어 OCR 모델로 합성 상세 제목의 직접 판독을 확인했습니다. 첨부 스크린샷 자체 픽셀과 Windows/MuMu 실기기 동작은 별도 확인이 필요합니다.

수동 경로 조건 6종(10콤보·다색팟·8개 연결·TPA·십자·L자)을 유지합니다. 파티와 팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개를 이용한 경로 탐색은 아직 미적용입니다. [경로 조건 안내](SOLVER_BENCHMARK.md#경로-조건-6종-v10117)

다운로드 파일 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정을 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
