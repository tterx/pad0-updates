# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_24.zip)

기존 프로그램을 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 설정과 개인 DB는 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.24: 결과 통계창을 **오른쪽 마나 아래**에 첫 결과 화면부터 표시하고 크리스탈 획득 화면을 나갈 때까지 유지합니다. ‘결과’ 제목의 직접 인식과 카드 아래 주황색 숫자 인식을 보완했습니다. 등록 재료 그림을 먼저 대조해 일치 카드의 ×N만 더하며 상단 ×2는 무시합니다. 같은 결과는 중복 집계하지 않습니다. [결과 통계 안내](FARMING_STATS.md#결과-통계-표시와-인식-보완-v10124)

사용자가 선택해 제공한 오류 3건을 분석했습니다. 잠금 보드의 링 색상 표본 누락으로 계산 버튼이 없던 2건을 보완하고 잠긴 나무→빛 오인식을 수정했습니다. 5초 제한에서 약 6.33초 드래그하던 경우는 시간 읽기 실패에도 경로 상한을 유지하고 보드 크기 및 실행 직전 시간을 확인하도록 보완했습니다. [실제 오류 분석](INVENTORY_PRECHECK.md#실제-오류-기록-분석과-수정-v10124)

검증: 회귀 220개, 실제 오류 보드 2개 통과, 실패 판에서 5초 상한 내 20회 이동의 5속성 경로를 약 1.3초에 탐색. 실제 Tk/창 관리자에서 결과창 우측 위치·5행·보유 +2·중복 방지 및 F7/경로 창 분리 확인. 한국어 OCR 실모델로 합성 결과 제목/×2/×4 직접 인식 확인. Windows/MuMu 실제 동작 확인은 별도 필요합니다.

자동 이미지 저장/최근 이미지 기록을 추가하지 않았습니다. 오류 저장/F12를 직접 누를 때만 진단 폴더를 만듭니다. F7 직접 확인 시 관리창 전면 표시, 자동 이름 등록 시 최소화 및 경로 계산 중 관리창 최소화를 유지합니다.

수동 경로 조건 6종을 유지합니다. 파티와 팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 아직 미적용입니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
