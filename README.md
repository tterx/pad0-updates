# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_31.zip)

프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 개인 DB와 설정은 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 **v101.31**: 사전 탐색 중에도 **5속성 수량 충족 여부**를 계속 표시합니다. 수량 확인 결과를 탐색 진행 문구로 덮어쓰던 표시를 수정했습니다.

- 탐색 중: ‘5속성 수량 충족 · 단축 시간 · 사전 탐색 중’
- 경로 발견: ‘5속성 수량 충족 · 탐색성공 · 버튼을 눌러 실행’
- 수량 부족: 기존 ‘5속성 수량 부족 · 빛 2/3’ 등 부족 속성·개수 안내와 ‘콤보 우선 실행’ 버튼

수량 충족은 각 공격색이 3개 이상이라는 뜻입니다. 경로를 실제로 찾았을 때만 탐색성공으로 표시합니다. [표시 안내](INVENTORY_PRECHECK.md#사전-탐색-중에도-색상-수량-표시-v10131)

기존 회귀 293개 통과. 실제 Tk/창 관리자에서 탐색 중·성공·부족 전환과 기존 창 동작을 확인했습니다. Windows/MuMu 실기기 확인은 별도입니다.

수량 부족일 때 사전 탐색을 생략하고 클릭한 실행만 콤보 우선으로 계산하는 동작, 5속성 설정 유지, 재료확인 버튼의 흰색 제목 바 바깥 위치, 통계창의 게임 포커스 연동을 유지합니다. 새 자동 이미지 기록은 추가하지 않았습니다.

적 콤보 무효 아이콘의 N+1 조건, 하단 콤보 가산 아이콘 자동 인식, 파티/팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 이번 변경에 포함하지 않았습니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
