# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_20.zip)

기존 프로그램을 종료하고 `시작.vbs`로 다시 실행하면 최신 버전을 확인합니다. 새 설치는 ZIP을 새 폴더에 압축 해제한 뒤 실행합니다. 설정과 개인 DB는 기존 LocalAppData/Pad0Overlay에서 읽으며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 v101.20: **크리스탈 관리창의 돌파 대상 이름 왼쪽에 등록 이미지를 표시합니다.** 이미 등록된 아텐도 기존 이미지로 표시합니다. 등록 직후 갱신하며, 대상이 바뀌거나 이미지가 없으면 이전 이미지를 지웁니다. 표시를 위한 새 파일이나 DB 항목을 만들지 않습니다. [사용 안내](FARMING_STATS.md#돌파-대상-이미지-표시-v10120)

v101.19의 OCR 의/외 보정과 이름만 저장된 항목의 이미지 연결을 유지합니다. 상세 제목은 아텐의 크리스탈로 확인하지만 재료 목록과 DB 이름은 아텐으로 저장합니다. 사용자가 실제 Windows에서 등록 성공을 확인했습니다. [이름과 이미지 연결](FARMING_STATS.md#이름만-저장한-항목에-이미지-연결-v10119)

회귀 199개 및 실제 Tk에서 등록 전/후 이미지 표시·캐시 재사용·대상 전환 시 제거·기존 DB 이미지 표시·필요7/보유2·관리창 고정 꺼짐 유지 확인. 새 이미지 표시 기능의 Windows 실기기 확인은 별도 필요합니다.

수동 경로 조건 6종을 유지합니다. 파티와 팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 아직 미적용입니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
