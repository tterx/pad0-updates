# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_33.zip)

프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 **v101.33**을 확인합니다. 개인 DB와 설정은 유지합니다.

적 콤보 무효의 **N+1 조건**과 하단 **콤보 가산**을 경로 탐색·캐시·실행 검사에 연결했습니다. 6 이하 무효면 최종 7콤보 이상, 확인된 가산 +2가 있으면 판에서 5콤보 이상입니다. 5속성과 적 요구 콤보를 함께 맞추며 콤보 우선으로 전환해도 적 최소 콤보는 유지합니다. 실행 직전 상태가 바뀌면 취소합니다.

작은 적 아이콘은 여러 색 구슬 배지인지 먼저 확인합니다. 오른쪽 남은 턴이나 회색 방패 75를 콤보 수로 쓰지 않습니다. 찾은 배지의 숫자가 불확실하면 실행 보류, 불확실한 가산은 0으로 처리합니다. 아이콘 자체를 놓치는 경우까지 차단하는 기능은 아니므로 **‘적 N콤보 이상’ 표시가 실제 적과 맞는지 확인**해 주세요.

테스트 327개 통과. 실제 첨부 판의 5속성+7콤보/44회 이동 및 실제 별도 프로세스, 실제 +2 화면 3개 OCR과 방패 75 제외, 재현 적 6/7/8 화면 OCR, 실제 Tk의 요구 수 표시·미달 차단을 확인했습니다. Windows/MuMu 및 실제 적 6/7 원본 픽셀 인식은 별도 확인이 필요합니다.

[콤보 조건과 검증 안내](INVENTORY_PRECHECK.md#적-콤보-무효와-가산-v10133) · [연전 통계 안내](FARMING_STATS.md) · [Windows 실행 안내](UPDATE_SETUP.md)

사전 탐색 대기 상한, 이번 실행만 콤보 전환, 연전 확인 통계, 중복 집계 방지와 기존 입력 보호를 유지합니다. 자동 이미지 기록은 추가하지 않았습니다. 파티/팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 실행 활용은 포함하지 않았습니다.
