# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_28.zip)

프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 최신 버전을 확인합니다. 개인 DB와 설정은 유지하며 배포 파일에 포함하지 않습니다.

업데이트 주소: https://raw.githubusercontent.com/tterx/pad0-updates/main/update.json

현재 **v101.28**: 시간 표시줄에 단축 구간이 있을 때만 자동 사전 탐색합니다. 정상 시간에는 OCR/경로 탐색을 시작하지 않습니다. 경로를 찾으면 ‘탐색성공 · 실행’을 표시하고 멈춥니다. 버튼/F6를 누르면 현재 판·가시·조건·시간·영역을 다시 검증한 뒤 사용합니다. 성공 표시만으로 이동하지 않습니다.

사전 탐색은 낮은 우선순위 프로세스 하나에서 1.2초 탐색/0.8초 휴식으로 후보를 바꿔 반복합니다. 판/시간/조건 변경, 다른 앱 전환, F10, 종료 시 취소합니다. [탐색 안내](INVENTORY_PRECHECK.md#단축-시간에서만-사전-탐색-v10128)

결과 통계는 다른 앱으로 전환하면 상단 고정을 풀고 뒤로 이동합니다. 게임으로 돌아오면 같은 결과의 통계를 다시 올리며 포커스를 강제로 가져오지 않습니다. 직접 닫거나 최소화한 창은 자동으로 되살리지 않습니다. [통계 안내](FARMING_STATS.md#다른-창-사용-중-통계-상단-고정-해제-v10128)

테스트 264개 통과. 실제 별도 프로세스 탐색과 원본의 5초/13초 구분, 취소 및 캐시 재검증, Windows 포커스 모의 검증, 실제 Tk/창 관리자 동작을 확인했습니다. Windows/MuMu 실기기 확인은 별도입니다.

기존 13초 배지 숫자 인식, 방해 드롭 인식, 개별 카드 ×N 집계와 중복 방지, F7/경로 계산 창 분리를 유지합니다. 자동 이미지 저장이나 최근 기록은 추가하지 않았습니다. 오류 저장/F12를 직접 누를 때만 파일을 만듭니다.

적 콤보 조건 자동 인식, 파티/팀 스킬 자동 인식, 체력 기반 독 판단, 배치 34개 활용은 이번 변경에 포함하지 않았습니다.

다운로드 보안경고는 [Windows 실행 안내](UPDATE_SETUP.md#다운로드-파일의-windows-보안경고)를 참고하세요. Windows 보안 설정은 자동 변경하지 않습니다.

이 저장소와 배포 파일은 공개되어 있습니다. 현재 실행기는 pad0_overlay.py만 자동 교체합니다. 실행기나 의존성이 바뀌면 전체 패키지를 다시 설치합니다.
