## 백그라운드 재료 파밍 — 첫 구현

잠입 확인 화면 오른쪽 반복/배속 스위치 아래의 **재료 파밍** 버튼으로 시작합니다. 마지막으로 F7/재료확인한 재료를 목표로 전투→보상 집계→같은 스테이지 재도전을 반복하고, 부족 수량이 모두 0이면 멈춥니다. **F10** 또는 메인창에서 중지합니다. 통계창 선택만으로 마지막 F7 목표를 바꾸지 않습니다.

전투 중 화면과 연속 터치를 MuMu ADB로 처리하며 **Windows 마우스·게임 창 전면 활성화를 사용하지 않습니다.** 다른 Windows 프로그램을 사용하면서 진행할 수 있는 구조입니다. MuMu 엔진은 실행 중이어야 하며 최소화/백그라운드 일시정지가 켜져 있으면 사용할 수 없습니다. 연결을 못 찾으면 메인창 **파밍 연결 설정**에서 MuMu의 `shell/adb.exe`와 기기 주소를 지정합니다.

**파티 설정**에서 현재 6명의 번호·레벨·스킬·각성을 읽고 정정할 수 있습니다. 공개 상세에서 확인한 몬스터 510종의 일본어 DB를 내장하고, 게임의 한글 이름 및 사용자 정정을 보존합니다. 잠금·속성 부족·시간 감소·상태이상·콤보 제한에 맞춰 스킬을 선택합니다. 무효 방패/공격력 감소처럼 그림만 보이는 상태는 아이콘을 먼저 등록해야 대응할 수 있습니다. 목표 재료를 모두 채우면 바탕화면 완료 알림을 표시합니다.

회귀 **383개** 통과. 모의 게임의 2회 누적→목표 종료, 집계 실패/다른 스테이지 차단, 실제 별도 프로세스의 모의 ADB 캡처/연속 입력/취소, 실제 OCR의 재현 한국어 화면과 실제 Tk 버튼 위치·숨김을 확인했습니다. **Windows/MuMu가 이 환경에 연결돼 있지 않아 실제 상세창·게임 터치·최소화·전체 클리어는 실기기 검증 전입니다.**
