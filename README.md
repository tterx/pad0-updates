# 퍼드0 올인원

[**프로그램 ZIP 다운로드 · v1.0.101**](https://github.com/tterx/pad0-updates/releases/download/v1.0.101/pad0_overlay_windows_v1_0_101.zip) · [전체 릴리스](https://github.com/tterx/pad0-updates/releases)

현재 표시 버전은 **1.0.101**, 자동 업데이트 내부 순번은 **309**입니다.

새로 설치할 때는 ZIP을 풀고 `시작.vbs`를 실행하세요. 기존 설치는 PAD0를 완전히 종료한 뒤 `시작.vbs`를 다시 실행하면 업데이트됩니다.

달인다속의 전체 잠금 판 스킬 확인과 F10 수동 전환을 수정했습니다. 입력 해제 후 오류 ZIP 저장과 별개로 수동 제어를 돌려주고, 늦은 저장 완료가 새 실행을 덮지 않도록 했습니다. Windows 검사 1,275개와 독립 번들 검사79개 통과. [변경 내용](docs/reviews/REVIEW309.md) · [검증 기록](releases/v1.0.101/release_checks309.json)
