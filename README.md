# PAD0 개인용 업데이트 배포

[최신 실행 패키지 다운로드](https://raw.githubusercontent.com/tterx/pad0-updates/main/pad0_overlay_windows_v101_174.zip)

프로그램을 완전히 종료하고 `시작.vbs`로 재실행하면 **v101.174**를 확인합니다. 개인 DB와 설정은 유지합니다.

이번 버전은 ADB 전용 제한을 해제하고 **공식 MAA 연결 방식**을 추가했습니다. 입력은 MAA의 MuMu SDK·MaaTouch·minitouch를 우선 확인하고, 연결이 불가능하면 scrcpy 제어 소켓과 Android 경로 실행기를 확인합니다. 화면은 MuMu 강화/MAA 무손실을 사용하며 네트워크 RAW·압축 RAW·minicap Direct/Stream도 선택할 수 있습니다. [적용 범위·검증 한계·라이선스](REVIEW174.md)

**파밍 연결 설정 → 화면 캡처 / 클릭·경로 입력**에서 선택합니다. 기본은 자동 선택이며, **캡처·입력 연결 테스트 (누름 없음)**로 화면과 입력 연결을 준비할 수 있습니다. MAA 도구가 없으면 처음 필요할 때 설치하고 이후 재사용합니다. 실제 FPS나 1ms 미만 입력 지연을 보장하지 않습니다. minicap은 JPEG이며 기본 자동 캡처는 무손실입니다. scrcpy는 입력 제어용으로 연결했습니다.

한 경로는 한 연결·한 접점으로 실행하고 시작 드롭·최종 판·UP 뒤 게임 반응을 확인합니다. F10도 원래 접점의 UP으로 정리합니다. 누른 상태에서 다른 입력으로 전환하지 않습니다. 실제 MuMu의 기존 동시 눌림 재발 해소와 성능은 실기 확인 전입니다. AI 재학습은 필요 없습니다.

## 백그라운드 재료 파밍 — 첫 구현

잠입 확인 화면의 **파밍 설정**에서 등록된 돌파 대상과 재료를 선택·저장한 뒤 **재료 파밍** 버튼으로 시작합니다. 재료 목록이 없다면 돌파 확인 화면에서 F7/재료확인으로 먼저 등록합니다. 선택한 재료의 부족 수량이 모두 0이면 종료합니다. **F10** 또는 메인창에서 중지합니다. 선택은 재실행 후에도 유지되며 보상 통계창에서 다른 목표로 바뀌지 않습니다.

전투 중 화면과 입력은 연결 설정에 따른 MAA/MuMu/scrcpy/Android 방식으로 처리하며 **자동 첫 퍼즐 시작 전 커서가 실제 퍼즐판 위에 있을 때만 판 밖으로 한 번 옮기며, 경로 이동은 선택한 컨트롤러로 연속 처리합니다. 게임 창을 전면 활성화하지 않습니다.** F10·정상 종료에서는 잔류 눌림 정리를 위해 Windows 마우스 UP과 MuMu 창 해제 메시지만 보냅니다. 다른 Windows 프로그램을 사용하면서 진행할 수 있는 구조입니다. MuMu 엔진은 실행 중이어야 하며 최소화/백그라운드 일시정지가 켜져 있으면 사용할 수 없습니다. 처음에는 **파밍 연결 설정 → 설정 마법사 시작**으로 설치 찾기→기기 연결→게임 화면 확인→저장을 순서대로 진행하세요. ADB는 `MuMuPlayer/nx_device/설치버전/shell/adb.exe`를 우선 찾습니다. 이전 경로가 저장돼 있다면 마법사의 **자동으로 찾기**를 다시 누르세요. offline 상태를 표시하고 재연결을 도우며, MuMu 자체의 ADB 허용은 필요한 경우 직접 켜야 합니다. 공식 사이트 버튼은 제거했습니다. 마법사 안의 **그림으로 보는 ADB·포트 설정**은 사용자가 공유한 참고 글을 엽니다. MuMu 설정에 5555,16384가 함께 표시되면 두 포트를 확인할 수 있으며, 목록에 없는 포트는 주소를 직접 입력해 연결할 수 있습니다. 내장 **경로 설정 방법**은 파일·기기 주소·offline 해결 순서를 보여줍니다. 연결을 못 찾으면 메인창 **파밍 연결 설정**에서 MuMu의 `shell/adb.exe`와 기기 주소를 지정합니다.

**파티 설정**은 클릭 시 앞으로 표시됩니다. **현재 파티 전체 읽기**는 상세를 4.2초 눌러 한 번 열고 화살표로 순회하며 한 명씩 저장합니다. 실패한 4번만 선택해 **선택한 슬롯만 읽기**로 보완할 수 있습니다. 이미 열린 상세에서도 선택 슬롯 기준으로 읽을 수 있습니다. 번호·레벨·스킬·각성을 확인하고 정정할 수 있습니다. 공개 상세에서 확인한 몬스터 510종의 일본어 DB를 내장하고, 게임의 한글 이름 및 사용자 정정을 보존합니다. 잠금·속성 부족·시간 감소·상태이상·콤보 제한에 맞춰 스킬을 선택합니다. 무효 방패/공격력 감소처럼 그림만 보이는 상태는 아이콘을 먼저 등록해야 대응할 수 있습니다. 목표 재료를 모두 채우면 바탕화면 완료 알림을 표시합니다.

최종 배포 내장 코드 **242개 통과(54.191초), 건너뜀 0개**입니다. 전체 검사에서 보완한 항목과 정확한 검증 범위는 [REVIEW174.md](REVIEW174.md)에 기록합니다. 실제 Windows/MuMu 성능과 전체 클리어는 실기 확인 전입니다.
