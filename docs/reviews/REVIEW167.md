# v101.167 방해 드롭 시작 검증

## 첨부 261023_045801_이동_025.zip

v101.166으로 실행됐으며, 커서가 퍼즐판 밖으로 옮겨졌고 SDK 단일 포인터가 사용된 것이 기록으로 확인됩니다. 마지막 실패 제스처에는 시작점 누름과 해제만 있으며 경로 MOVE는 전송하지 않았습니다.

실제 game.png와 held.png에서 3행 1열(0 기준 12)의 방해 드롭이 정확히 들렸습니다. 해당 칸의 기본 유형은 J이지만, 들려서 반투명해진 중앙만 작게 잘라 분류하면 B가 나왔습니다. 원본 무늬와 일치하는 후보 4개가 있었음에도 마지막 색상 조건에서 모두 거부되어 `start_lift_unconfirmed`로 중지됐습니다.

024의 다른 칸 들림과 구분됩니다. 이번 기록에서는 잘못된 위치로 들어간 증거가 없으며, 실제 시작 방해 드롭을 검증기가 잘못 거부했습니다. 이번 수정은 이 재현을 대상으로 합니다.

## 변경

방해 드롭(J)으로 확인된 시작 칸에 한해, 중앙 분류가 달라도 다음을 모두 확인하면 넓은 원본 무늬로 유형을 확인합니다.

- 시작 칸 및 위쪽 영역에 실제 들림 변화가 있음.
- 기존 공간·크기 범위 안에서 중앙 무늬 상관도 0.85 이상, MAE 0.11 이하로 원본과 맞음. 기존 일반 비교보다 엄격한 조건입니다.
- 잘리지 않은 넓은 이미지에 방해 드롭의 어두운 윤곽이 있고, 전체 회색 무늬도 원본과 상관도 0.65 이상으로 일치함.
- 인접 영역을 제외한 판이 20칸 이상 유지됨.

전체 드롭 분류기나 AI 모델을 수정하지 않았습니다. 물 드롭을 전체적으로 방해로 바꾸지 않으며, 다른 칸에서 들린 방해 드롭·커서만 있는 화면·정지한 판·단색 덮개는 통과시키지 않습니다.

실제 첨부 재현에서는 중앙 무늬 상관도 약 0.886, MAE 약 0.102, 넓은 무늬 상관도 약 0.710, 주변 판 유지 24칸으로 시작 검증을 통과합니다. 실제 경로 이동과 2스테이지 완료는 개발 환경에 MuMu가 연결되지 않아 확인 전입니다.
