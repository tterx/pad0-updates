# v101.176 ZIP033 방해 드롭 시작 확인

## 원인

261023_181949_이동_033.zip은 v101.175의 MuMu 강화 캡처와 MAA 입력을 사용합니다. 퍼즐판과 사용자 AI 모델은 30칸 모두 같은 종류로 읽었고, 시작 칸인 2행 3열도 방해(J)로 정확히 읽었습니다. 실패는 경로 계산 이후, DOWN으로 드롭을 잡았는지 확인하는 단계에서 발생했습니다.

시작 확인은 원래 칸의 중앙 무늬를 작은 영역으로 잘라 비교합니다. 이번 방해 드롭은 그 영역만 보면 파란 얼굴이 대부분이어서 물(B)로 분류됐고, `start_baseline_colour_mismatch`로 이동 전 취소됐습니다. held.png에는 해당 방해 드롭이 실제로 들려 있습니다. 기존 v101.167 보완은 기준 무늬가 J로 판정된 뒤의 반투명 들림에 적용되므로, 이번 기준 무늬 오판은 처리하지 못했습니다.

실패 제스처는 마지막 DOWN/UP 한 쌍이며 MOVE는 없습니다. 보고서 앞의 MOVE 기록은 이전 제스처이므로 이번 시작 실패와 합쳐 이동 성공으로 판단하지 않습니다. 강화 캡처는 기준 화면 약 56ms, 시작 확인 합계 약 256ms로 기록돼 있어 이 사례의 취소 사유는 캡처 지연이 아닙니다.
