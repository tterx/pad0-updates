# v101.179 첨부판 경로·잠금·가시·구름·속성 흡수

## 첨부 확인

메모 6개 항목과 `경로실행오류.png`, `어둠속성흡수.png`를 검토했습니다. 경로 오류 화면의 30칸 인식은 크기 변경과 좌표 반올림에도 같았습니다. 해당 판은 24회 이동으로 직접 5속성·7콤보, 회복 6개 매치, 독 매치 0개가 되는 경로를 재생 검증했습니다. 스크린샷에는 실제 실패 시점의 경로/입력 로그가 없어 과거 취소 원인을 하나로 확정하지는 않습니다.

기존 경로 재사용은 좌표가 1px 달라지거나 체력에 따른 회복 목표가 바뀌어도 즉시 무효 처리했습니다. 새 코드는 실제 판·가시 위치를 대조하고 작은 좌표 반올림 차이만 허용한 뒤 현재 목표·적 콤보·가산·이동 상한으로 경로를 다시 검증합니다. 실제 드롭 변경·큰 위치 변경·미확인 적 조건·시간 부족·목표 미달·F10 이후 결과는 계속 차단합니다.

## 변경 동작

- 잠금이 있어도 기존 첫 탐색의 실제 경로가 5속성·6콤보와 현재 목표를 만족하면 잠금 해제를 아낍니다. 수량만으로 면제하지 않으며 실패하면 해제/단축을 다시 검토합니다. 바인드·각성무효·위급한 시간·무효/흡수 대응은 계속 먼저 처리합니다.
- 수동 경로 창의 숨겨져 있던 속성 확인 줄을 표시하고, 실제 검증한 속성 수와 확정 최소 콤보/필요 콤보를 함께 보여 줍니다. 수량 충족과 검증된 경로를 구분합니다.
- 첨부판의 휘어진 금속 가시 두 개를 기본 이미지 판독에 추가했습니다. 독/방해 드롭 위 가시는 물리 무늬 증거가 있어야 인정합니다. 가시 위치는 판 검증과 UI에 유지합니다.
- 현재 중지 세대에서 5초 이내 확인한 체력이 60%를 넘으면 탐색 점수의 가시 회피 우선순위를 낮춥니다. 실제 가시를 없앤 것으로 기록하지 않으며 독 정책은 바꾸지 않습니다. 체력이 낮거나 미확인·오래된 경우 회피를 유지하고, 입력 직전 정책이 달라지면 다시 계산합니다. 구름으로 가시 여부가 미확인인 칸은 이 완화에서 제외하며 실제 가시 수로도 세지 않습니다.
- 구름 지속 숫자와 관계없이 미확인 칸의 원래 중심을 한 번씩 확인합니다. 재누름과 숫자를 피하는 좌표 이동을 제거했습니다. UP 후 두 복원 프레임을 기다리며 실패 시 입력 없이 중단합니다.
- 속성 흡수는 색이 아닌 화살표·세 별·마름모 무늬로 판독합니다. 등록한 같은 위치의 제외 판단은 유지하며 적의 공격 표시 주변에서 확인합니다. 속성별 개별 선택 없이 전체 속성 흡수 무효 스킬에 연결합니다.

## 검증 범위

실제 첨부 이미지의 인식·경로 재생과 자동 스킬/수동 경로/구름 입력 회귀를 검사합니다. Windows/MuMu 장치가 연결되지 않아 실제 전투 클리어와 입력 체감 속도는 검증 범위에 포함하지 않습니다. AI 모델 가중치·학습 자료·연결 프로필·이동 전송 속도는 변경하지 않습니다.

기본 핵심 목록은 341개로 유지하며 새 회귀 31개를 관련 영역에 추가했습니다. 실제 이미지와 경로 재생, 낮거나 오래된 체력/중지 세대, 구름 미확인 가시, 자식 탐색의 원래 관측 시각, 일반 다색 캐시의 체력 재확인, 실제 Tk 조건 표시를 포함합니다.

전체 프로필 1,563개를 실행해 1,562개가 통과하고 과거 콤보 스킬 순서 기대 1개가 실패했습니다(464.335초, 수집 포함 464.911초, 건너뜀 0개). 해당 검사는 적의 명시적 콤보 조건이 있어도 첫 탐색 실패 뒤에 가산을 쓰도록 기대했습니다. 최신 요청인 “적 콤보 조건이면 콤보 가산 우선”에 맞춰 먼저 사용하고 새 가산을 읽은 뒤 한 번만 탐색하는 것으로 기대값을 갱신했습니다. 프로그램 코드는 이 실패 때문에 바꾸지 않았습니다. 해당 모듈 4개는 0.983초에 모두 재검증했습니다. 기대값 갱신 후 전체 프로필을 다시 실행한 결과로 표기하지 않습니다.

최종 배포용 내장 소스를 직접 불러 새 회귀 31개, 기존 스킬/구름/회복 회귀와 8개 내장 모듈 경계 검사까지 **87개 모두 통과**했습니다(56.505초, 오류·건너뜀 0개). 이 검사는 실제 MuMu 기기 대신 이미지와 시험 입력 장치를 사용하며 실기 전체 클리어 또는 입력 지연 측정으로 해석하지 않습니다. ZIP은 허용된 배포 파일 목록과 CRC, 버전, 내장 소스·모듈 일치를 확인합니다. 개인 DB·학습 이미지·오류 ZIP은 배포하지 않습니다.
