# v101.187 두 시작 경로 비교와 현재 판의 중복 판독 감소

044는 파티창에서 바로 시작한 기록이며 045는 재료 선택·스테이지 이동을 거친 기록입니다. 둘 다 v101.186이고 같은 MuMu 강화 캡처(64)·MAA 입력 요청(14), 같은 1920×1080 기기 연결을 사용했습니다. 두 경로 모두 최종 실제 판이 계산과 일치했고 손 떼기 후 게임 반응도 확인됐습니다. 이전 043의 AndroidControl 전환은 이번 두 기록에 없습니다.

044는 아텐으로 부족한 속성을 생성한 사용 기록이 있고 045는 스킬 사용 없이 이동했습니다. 경로 길이·방향 전환·스킬 유무가 달라 전체 시간을 그대로 속도 차이로 해석할 수 없습니다. 도전 전까지는 3.359초/6.797초이며 도전 준비 시각부터 첫 안정 판까지의 차이는 약 10.531초/10.250초로 비슷합니다. 이 구간에는 게임 로딩·팀 조건 OCR·판독이 섞여 있으므로 전부 게임 로딩 시간이라고 단정하지 않습니다.

공통 처리에서는 가림 없는 현재 판을 확인한 뒤 구름 기억을 저장하려고 동일 이미지의 색·가시·가림을 다시 읽고 있었습니다. 현재 프레임을 검증한 `background_board` 결과를 그대로 구름 기억과 가시 근거에 전달해 이 재판독을 없앴습니다. 색/가시 판독은 2회→1회, 가림 검사는 3회→2회입니다. 다른 프레임의 인식 결과를 재활용하는 방식이 아니며 매번 현재 이미지의 유효성 검사를 통과해야 합니다. 구름·암흑 칸이 있거나 판이 유효하지 않은 경우 기존 확인 경로를 유지합니다.

같은 이미지·알고리즘·입력 장치 동작 없이 각각 초기 1회 후 3회 측정의 중앙값입니다. 두 판 모두 원래 인식 결과와 동일한 드롭을 확인했습니다. 수치는 이 개발 환경의 판독 함수만 측정한 결과이며 실제 MuMu 전체 반응이나 드래그 시간이 같은 비율로 줄었다는 뜻은 아닙니다. 이동 간격·시작 누름·방향 전환·마지막 안정 대기·최종 판 검증은 변경하지 않았습니다.

오류 저장에는 이동 전 누적 시간, 판 관찰 시간, 현재 판 탐색 시간을 추가합니다. 스킬이나 조건 재확인으로 판을 다시 관찰한 시간도 포함합니다. 기존 시작/이동/해제 기록과 나눠 다음 실기에서 남은 지연을 구분할 수 있습니다.

새 회귀 6개는 실제 두 판을 한 번만 판독하면서 현재 결과를 기억하는지, 무효 화면 배제, 구름 발생 시 최근 확인 판 사용, 보이는 칸 변화 시 숨은 색 추정 차단, F10 무효화·정지 세대·마우스/Android 공간·영역 경계 분리, 가시 근거 유지를 검사합니다. 새 6개 모두 통과했습니다(6.313초). 기본 핵심 341개는 유지하고 파밍 영역의 기존 구름·스킬·경로 검증을 함께 실행합니다. 실제 Windows/MuMu 체감 속도는 실기 확인 전입니다.

최종 핵심·파밍 780개 모두 통과했습니다(253.579초). 최종 내장 배포 코드의 실제 첨부판·구름/암흑·가시·정지/영역 경계·스킬/회복·전투 연출·모듈 경계 83개도 모두 통과했습니다(87.375초). 오류·건너뜀은 각각 0개입니다. 이동 간격을 조정하지 않았으며 실제 MuMu 체감 향상은 별도 확인 대상입니다.
