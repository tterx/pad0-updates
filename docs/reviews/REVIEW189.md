# v101.189 실제 퍼즐판 자동 속도 테스트

메인 창의 **자동 속도 테스트 · 실제 퍼즐 이동**을 누릅니다. MuMu에서 구름·암흑 없는 전투의 퍼즐판을 연 뒤 **테스트 시작**을 누르세요. 시험 중 턴과 전투가 진행될 수 있습니다. 파밍·수동 경로·재료 확인 등 다른 입력은 시험 정리가 끝날 때까지 막으며 **중지/F10/창 닫기**로 취소할 수 있습니다.

느린 속도부터 이동 샘플 간격과 모서리 대기를 함께 시험합니다. 최대 5단계를 시도하고, 통과 범위에서 한 단계 여유 있는 설정을 선택해 새 판에서 2번 더 확인합니다. 같은 설정의 성공이 총 3번 확인돼야 저장합니다. 전체 최대 7회이며, 첫 단계부터 실패하거나 재검증·시간 확인·손 떼기 확인이 실패하면 새 설정을 적용하지 않습니다. 기존에 저장된 속도는 유지합니다.

저장된 속도는 자동파밍의 실제 MAA 이동과 경로의 시간 상한에 함께 적용합니다. 느리게 이동하면서도 기존의 긴 경로를 그대로 허용하지 않습니다. 기기·해상도·ADB/에뮬레이터 설치·MAA 연결 조건이 달라지면 적용하지 않고 기본 속도를 사용합니다. 재시험하거나 **기본 속도로** 복원할 수 있습니다. 기본 연결은 이전과 같은 MuMu 강화 캡처와 MAA Android 터치(MaaTouch 우선, minitouch 내부 보조)입니다.

## 전달할 데이터

성공·실패·중지 결과를 기존 오류 폴더에 `261024_173500_속도_048.zip` 같은 이름으로 저장합니다. 날짜·시간과 마지막 번호는 실제 생성 시점과 기존 오류 순번을 따릅니다. 완료창의 **결과 ZIP 경로 복사**로 위치를 확인하고 해당 ZIP을 채팅에 첨부하면 됩니다.

ZIP에는 속도별 결과·실제 경로·예상/관찰 판·이동 이벤트·소요 시간·모서리 지연·손 떼기 증거와 판/시간 표시줄 이미지를 넣습니다. 전체 계정 화면과 설정 파일은 넣지 않으며 연결 식별값은 해시로 기록합니다. `설명.txt`와 `report.json`의 권장 설정은 시험 결과이고, 실제 설정 저장 성공 여부는 프로그램의 완료 메시지에서 확인합니다. 중지한 뒤 도착한 성공 결과나 파일 저장 실패는 설정에 적용하지 않습니다.

## 047 분석과 시험 기준

047은 v101.188의 MAA Android 입력 요청(6), MuMu 강화 캡처(64)를 사용했습니다. 시작 드롭은 첫 확인에서 들림이 확인됐고, 32칸 이동·23번 방향 전환에 실제 이동 2.834초, 가장 긴 MOVE 간격 34.486ms이며 50ms 초과 간격은 없습니다. 손 떼기 응답도 기록됐습니다. 그러나 최종 실제 판이 계산과 다른 칸은 **13·19·20·25·26번**이었습니다. 046처럼 시작 드롭 확인 전 정지한 사례와 다릅니다. 이 기록만으로 원인을 속도 하나로 확정하지 않습니다.

시험 경로는 8~24칸으로, 가시·방해·독을 피하고 같은 칸으로 되돌아오지 않으며 여러 모서리와 관찰 가능한 색 변화를 포함합니다. 같은 색끼리 교환해 경로 누락이 감춰지는 경우도 배제합니다. 단순 입력 전송 응답으로 통과시키지 않고, 누른 상태의 실제 판 검증과 UP 이후 화면 변화·안정 판을 확인합니다. 원래 판·시작 드롭·실제 최종 판 검증을 완화하지 않았습니다.
