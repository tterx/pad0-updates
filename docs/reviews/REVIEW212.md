# v1.0.4 / 업데이트 순번 212: 연전 OK의 ㅇK OCR 오독 보완

086은 v1.0.3에서 전투와 보상 집계를 끝내고 연전 확인에 도달했습니다. 스테이지 재판독은 없었으며 cached_entry 6-15가 기록됐습니다. 그만두기 [416,665,784,777], OK [815,665,1185,777] 버튼 영역은 정상 검출됐습니다. 그러나 한국어 OCR이 영문 OK를 두 배율 모두 ㅇK로 읽고 0.75537/0.75464를 반환해 기존 .85 기준 및 문자열 검사에서 중지했습니다.

이미 제공됐던 084 화면에서 확인한 OK·그만두기 글자 마스크를 작은 비트 템플릿으로 내장했습니다. 이번 086은 템플릿을 만드는 데 쓰지 않았으며 실제 픽셀 비교에서 두 버튼 모두 IoU 1.0으로 일치합니다. 같은 위치의 큰 흰색/주황색 버튼 쌍을 확인한 뒤 선택할 버튼의 소모량을 제외한 글자만 비교합니다. 글자 너비/높이 비율, 중앙 위치, 이진 무늬 IoU>=.92가 맞으면 OCR과 무관하게 확인하며 색상만으로 누르지 않습니다. 다른 문자·빈 글자·버튼 쌍 누락은 이 확인을 통과하지 않습니다. 모양 확인이 어려우면 기존 두 배율 OCR/.85 판독을 그대로 사용하며, OCR 기준을 낮추거나 ㅇK를 무조건 OK로 치환하지 않았습니다.

기존 연전 헤더 확인·집계 완료 확인·재료 미충족 OK/충족 그만두기·중복 클릭 방지·그만두기 후 화면 전환 확인·완료 소리/알림·F10을 유지합니다. 입력 백엔드·속도를 변경하거나 재학습하지 않았습니다. 1.0.3에서 학습한 방해·물 모델과 기존 사용자 모델을 유지합니다.

실제 086 하단 버튼 이미지를 비공개 재현 자료로 보관하고 OCR의 ㅇK/.755 응답에도 실제 모양으로 진행하는지 확인합니다. 성공 시 진단 source=paired_button_glyph_artwork와 artwork.glyph_iou/aspect_delta/글자 영역을 기록합니다. 새 검사는 실제 픽셀을 비교하며 MuMu를 조작하지 않습니다. Linux/Windows 및 공개 ZIP 검증 수치는 release_checks212.json에 기록합니다.
