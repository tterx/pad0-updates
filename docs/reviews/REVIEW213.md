# v1.0.5 / 업데이트 순번 213: 사용할 수 없는 우선 스킬의 차선책

087은 v1.0.4에서 마나 43,600을 집계한 뒤, 바인드된 3·4번과 대기 중인 해제 담당 때문에 중지했습니다. 화면의 준비 표시에는 1·2·5번이 있었지만, 기존 우선순위 필터는 해제 후보 0번만 검토했습니다. 따라서 준비된 관통·잠금 해제가 다음 선택으로 넘어오지 못했습니다.

사용 가능한 최우선 대응이나 현재 쿨타임으로 효용이 확인된 단축을 먼저 검토합니다. 둘 다 불가능하면 그 결정에서만 해당 효과를 unavailable_skill_effects로 제외하고 다음 우선순위를 검토합니다. 실제 바인드·각성무효·적 효과가 사라졌다고 처리하지 않습니다. 매 새 화면/결정에서 다시 검토하므로 해제가 준비되면 다시 최우선입니다.

해제 대기 중 준비된 관통, 잠금 해제, 조작시간 대응, 콤보 가산, 판 보완, 저체력 회복 등 현재 유용한 차순위로 내려갑니다. 유용한 자동 스킬이 없거나 한 턴 사용 한도에 도달하면 현재 판에서 가능한 회복·콤보 경로로 턴을 진행합니다. 초기 선해제 중지와 판독 후 해제 대기 반복을 제거했습니다. 바인드된 슬롯, 이미 쓴 스킬, 자동사용 해제, 미확인 스킬과 정책 제한은 유지합니다. 단축은 지금 관찰한 쿨타임으로 유효한 경우만 사용하며 카탈로그 기본턴이나 미인식 숫자로 추측하지 않습니다.

087 실제 이미지·등록 프로필 재현에서 해제 불가 후 라피네의 관통(1번), 다음 라그나로크의 잠금 해제(5번)를 선택합니다. 번호는 내부 0부터 시작합니다. 모든 대응이 대기 중인 조건에서도 정상 판과 시간·콤보를 확인하고 실제 탐색 경로를 재검증해 한 번의 드래그로 턴을 진행하는 코드 검사를 추가했습니다. 해제 준비 시 최우선, 다른 적 효과의 미가용 차선책, 저체력 회복, 유효 단축, 자동사용/바인드 제외, 발동 실패 시 중지 검사를 포함합니다.

스킬이 실제로 발동했는지 불확실한 경우에는 여전히 중복 사용 없이 중지합니다. 판·시간·경로·이동 및 해제 후 게임 반응 검증, F10, 오류 ZIP, SDK와 속도 설정, 방해·물 모델, 연전 정책은 유지합니다. 실제 MuMu 게임 조작은 포함하지 않으며 Linux/Windows 및 배포 검사 수치는 release_checks213.json에 기록합니다.
