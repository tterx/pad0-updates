# v1.0.24 / updater232

팀 모드 표시를 지우기&콤보로 수정했다. 파티에 TPA 각성이 있으면 수동·자동의 선택 모드에 우선해 TPA 보유 캐릭터의 주·부속성에만 정확한 4개 매치를 찾는다. 경로 점수는 TPA 그룹 수를 먼저 최대화하고, 동수일 때 6콤보 달성 및 추가 콤보를 비교한다. 6콤보 때문에 확보한 TPA 수를 줄이지 않으며 6콤보 미달도 TPA가 하나 이상이면 실행할 수 있다. 검색은 시간 제한 안의 최선이며 전역 최적 보장은 아니다. 이미 매치된 판도 실제 한 칸 이동을 확인한다.

택틱에 드롭 생성 항목을 추가했다. 현재 파티의 No368·247의 한글/일본어 생성 설명을 generation 효과로 등록한다. TPA 가능한 속성의 드롭 수가 부족하거나 탐색 후 TPA가 없으면 생성 스킬을 선택한다. 둘 다 쿨타임이면 현재 관측된 쿨타임을 가진 생성 스킬을 대상으로 하는 준비된 턴 단축을 선택한다. No119·120의 기존 haste 설명과 실제 쿨타임 확인을 사용하며 특정 슬롯을 강제로 누르지 않는다. 바인드·각성무효 해제 및 생성 전에 필요한 잠금 해제가 앞선다. 생성·단축 모두 불가하면 판 정리로 턴을 진행해 쿨타임을 충전한다.

콤보 가산 드롭은 드롭과 같이 움직이는 ComboOrb 메타데이터를 갖는다. 매치 그룹에 속해 실제로 지운 가산 드롭 1개당 +1, 두 개는 +2를 스킬 가산과 별도로 합산한다. 지우지 않은 가산 드롭은 합산하지 않는다. 탐색 캐시와 TPA 경로 문맥에 가산 위치를 포함해 동일 색 드롭끼리 바꿔도 다른 상태로 탐색한다.

가산 아이콘 보조 모델은 tools/train_combo232.py에서 원형 세 개의 대각선 연결과 주황색 바탕을 렌더링한 자료로 개발환경에서 학습했다. 학습2400개·별도검증800개에서 양성 재현율88%, 음성400개 중 오탐0. 실제 콤보가산 아이콘의 원본 PNG 파일은 이번 실행 환경에 제공되지 않아, 이 수치는 실제 게임 인식률이 아니다. 원본 사용자 이미지로 학습하거나 실기기에서 정확도를 확인했다고 주장하지 않는다. 확신 기준 미달이면 가산으로 합산하지 않는다. 기존 실제 가산 없는 판30칸 오탐0과 렌더링한 두 아이콘의 관측/이동/합산을 검사했다. 모델은 내장 고정 자료이며 사용자 환경에서 학습·자료 저장을 하지 않는다. 원본 게임 이미지의 양성 검증이 남아 있다.

검사: tests/test_tpa232.py (TPA 다중 그룹 보존, 6콤보 선택, 생성/단축, 실제 파티 설명, 가산 위치 이동과 합산, 모델과 캐시). 이전 다색 회귀는 TPA 없는 파티의 다색 규칙으로 범위를 명시했고, TPA 우선 선택은 새 회귀에서 별도로 검사한다. 기존 다른 모드의 적 콤보 확인 규칙은 유지한다. 배포의 정확한 검사 수·소스 커밋·ZIP 및 자동 업데이트 검증은 release_checks232.json에 기록한다.
