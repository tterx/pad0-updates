# v1.0.26 / updater234 — 어둠4개·9초 판의 탐색 누락

첨부 판을 색상으로 전사했다: HHBBRR / HRGHPR / BBRPHH / GBRPRG / RPGGHH. 어둠은 인덱스10·15·21·25에 있으며, 보이는 가산 아이콘은10·23이다. 원본 PNG 파일로 OCR을 실행한 결과가 아니며 인식기 정확도를 검증했다고 주장하지 않는다.

해당 판에는 [25,26,27,21,15,9,10,16,15]의 실제 8이동 경로가 있다. 아래에서부터 첫째 줄 둘째 칸에서 오른쪽·오른쪽·위·위·위·오른쪽·아래·왼쪽으로 움직이면 어둠9·15·21·27이 세로로 맞춰진다. 6콤보가 없어도 유효한1TPA다. 이전 일반 탐색은 개발환경0.5초에서 TPA0을 반환했으며 2초에서는 찾는 등 계산 속도에 민감했다. 이는 전사한 판의 탐색 재현이며 사용자 환경의 실제 인식 결과/실기 원인 확정은 아니다.

TPA가 없는 초기 판에서는 해당 속성 드롭의 위치 비트마스크와 현재 잡은 칸만 사용하는 별도 탐색으로 정확한 직선4개를 먼저 확보한다. 시간·이동 상한·허용 시작 칸·취소를 지킨다. 경로는 원래 전체 판에 다시 적용해 검증하고, 가산 아이콘 및 가시 위치도 함께 이동시켜 평가한다. 유효한 결과는 즉시 최선 경로에 보존하고 일반 탐색의 출발 상태에도 추가해 TPA 수와 선택적6콤보를 개선한다. 색 위치만 같아도 다른 색 배치/가산 위치는 일반 탐색에서 구분한다. 실제 경로 길이로 이동 상한을 다시 제한한다. 원래 여러 TPA가 있는 판은 기존 매치를 보존하며 별도1TPA 생성 탐색을 하지 않는다.

TPA 성공 개수는 실제로 지워지는4개 그룹으로 계산한다. 셋이 줄을 이뤘지만 넷째가 옆에 붙어 지워지지 않는 모양은4매치 성공으로 표시하지 않는다. 템플릿 근접도는 탐색 안내용으로만 사용한다.

tests/test_tpa_seed234.py: 보고된 판8이동 증명, 짧은 예산의 전용 탐색, 실제 일반 solve_path와 가산 이동, 4방향 반전, 이동/시작 제한/취소/수량부족, 가짜4연결 배제, 기존3TPA보존,9초 수동worker에서 실행 전 검사까지 검증한다. 시간 측정은 성능 보장이 아니며 탐색은 최단/전역 최적을 보장하지 않는다. 가산 아이콘 모델/타이머OCR/입력 방식과 속도는 변경하지 않았다. 실제 MuMu 및 원본 이미지 인식 검증은 남아 있다.

배포 커밋·검사 수·해시 및 실제 업데이트 검증은 release_checks234.json에 기록한다.
