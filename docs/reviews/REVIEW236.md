첨부107의 실패는 이름 등록 이후 획득 던전 목록에서 EX1을 확정하지 못한 경우다. 기존 번호 문법은 숫자-숫자와 SP만 지원했다. EX를 정식 문법에 추가하고 분리된 EX/숫자 토큰도 공간적 인접성을 확인해 연결한다. E1을 EX1로 추측하지 않는다. 번호 직접 인식 영역은 초상화 하단이 끼지 않도록 좁혔다.

원본 game.png를 실제 한국어 RapidOCR로 검사해 10-10과 EX1을 모두 확인했다. 누락 번호0개. 수량·이름은 이번 수정 대상이 아니다.

출현 목록은 주황 스크롤 막대가 남아 있으면 정지 화면을 끝으로 간주하지 않는다. 최대3회 정체 재시도 후에도 움직이지 않으면 미완료로 중지하며 preview_verified를 저장하지 않는다. 아래 끝을 확인하면 종료한다. 페이지 상한은24로 늘렸다. 막대 없는 짧은 목록은 기존 정지 화면 검사로 끝을 확인한다.

EX 문법·분리 토큰·스크롤 후 아래 페이지 저장·정체 시 완료 저장 차단을 가짜 입력으로 검증한다. 원본107은 획득 던전 화면이며 출현 목록 스크롤 실기 영상은 없다. 실제 MuMu 입력은 미검증이다.
