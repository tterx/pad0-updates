# v1.0.134 · 달인다속 재접속 첫 화면과 건너뛰기

246번은 v1.0.132에서 실행됐습니다. 선택된 Android 앱을 재실행한 기록은
있으나 로고와 영상 입력은 비어 있습니다. 마지막 프레임의 게임 영역
전체가 검은색이었습니다. 당시 독립 ADB 캡처는 없어 MuMu 강화 캡처만
검었는지 게임 화면도 검었는지는 확인할 수 없습니다.

재실행 후 로고와 시작 화면은 250ms 대기 간격으로 확인합니다. 확인된
로고 뒤 시작 버튼이 보이면 바로 그 버튼을 누릅니다. 로고를 확인하기
전에 크리처 영상이나 오른쪽 위 흰색 ‘건너뛰기’ 버튼이 나타나는 흐름도
처리합니다. ‘건너뛰기’는 흰색 버튼 안의 정확한 문구로 확인합니다.
필요하면 글자 영역을 원본과 두 배 크기로 다시 읽습니다. 새 캡처 두 장,
최대 영상 클릭 횟수, F10과 게임 전면 확인을 적용합니다.

검은 캡처가 이어지면 같은 MuMu 기기에서 독립 ADB 캡처를 읽습니다.
거기서 확인한 화면도 같은 위치를 두 새 프레임에서 확인한 뒤 입력합니다.
두 캡처가 계속 검으면 입력을 보내지 않고 기다립니다.

Codex에서 246번 검은 캡처, 243번 실제 시작 화면, 245번 실제 크리처
화면을 판독했습니다. 흰색 ‘건너뛰기’ 버튼, 화면 전환, 독립 ADB 캡처,
F10 취소는 모의 환경에서 검증했습니다. 실제 MuMu 입력은 미검증입니다.

Codex 소스 검사 58개와 배포 코드 검사 36개를 통과했습니다.
