# v1.0.135 · 장시간 파밍 메모리와 종료 정리

기존 마나 집계는 파밍을 계속하는 동안 매 판의 상세 기록을 보관했습니다.
새 버전은 최근 128건을 보관하면서 누적 합계와 미확인 횟수를 계속 계산합니다.
연속으로 들어오는 같은 회차는 한 번 집계합니다. 화면 표시 대기열에는
렌더링에 필요한 판과 가시 상태를 넣습니다. 이미 쓰기가 비활성화된 진단
메시지와 사용하지 않던 화면 복사본을 빼고, 보상 스크롤 원본은 오류
저장이 끝나거나 집계가 마무리되면 해제합니다.

종료 시 진행 작업을 취소하고, 연결별 ADB 명령과 원래 터치를 정리합니다.
동시에 진행되는 명령은 각 프로세스 핸들로 추적합니다. 캡처와 별도 입력
연결은 둘 다 닫고, 메인 창 종료 시 파밍 작업이 정리될 시간을 둡니다.
Windows에서 PAD0는 종료 시 정리되는 프로세스 그룹을 사용합니다.
PAD0가 시작한 ADB 서버나 보조 프로세스는 이 그룹에 속합니다.
기존 공용 ADB와 이미 열려 있는 MuMu는 유지합니다.

Codex의 50,000회 마나 집계 비교에서 추적된 보관 메모리는
14,774,216바이트에서 41,152바이트로 줄었으며 누적값 520,000과 미확인
10,000회는 일치했습니다. 실제 로컬 하위 프로세스 두 개가 취소와 함께
종료되는 것과 별도 프로세스가 살아 있는 것을 확인했습니다. Windows
프로세스 그룹 설정은 모의 API로 검증했습니다. 실제 Windows/MuMu의
장시간 메모리와 네이티브 보조 프로세스 종료는 미검증입니다.

Codex 소스 검사 99개와 배포 코드 검사 55개를 통과했습니다.
