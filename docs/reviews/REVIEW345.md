# v1.0.136 · 달인 다색 파밍 보상 저장과 연전 복구

248번은 크리스탈 보관 한도 안내가 있는 결과 화면에서 Windows가
`crystal_ledger.json` 교체를 거부해 멈췄습니다. 로그에는 오류 5가
기록되어 있으며 파일을 막은 프로그램은 확인되지 않았습니다.
오류 ZIP의 기본 보상 기록은 직전 집계분입니다. 문제의 보상 집계는
완료됐다고 볼 수 없으며 이 업데이트는 과거 수량을 추정해 입력하지
않습니다.

달인 다색 재료 파밍의 크리스탈 보상은 이번 회차의 수량과 기록을
고유한 임시 파일에 함께 기록합니다. Windows 접근 또는 공유 충돌
오류 5, 32, 33이면 최대 1.2초 동안 같은 파일 교체를 재시도합니다.
성공하면 한 번 집계하고 다음 버튼을 누릅니다. 계속 막히면 기존
파일을 보존하고 이번 회차의 미저장 보상과 해당 화면을 오류 ZIP에
남깁니다.

247번은 8-3 연전 확인에서 OK의 누름·뗌 명령이 기록됐지만 20초 안에
전투 진입을 확인하지 못한 경우입니다. 처음 누른 뒤 4초가 지나도
같은 연전 화면이 남아 있으면 스테이지 번호, 파티, 버튼을 새로
확인한 후 OK를 한 번 더 누릅니다. 다른 화면, 다른 파티, 일반 및
별표 스테이지 불일치, 진행 중인 터치와 F10에서는 재입력을
허용하지 않습니다. 247번 화면에서 나타난 OK 글자의 렌더링 차이는
재입력 확인에만 적용합니다.

첨부 화면을 사용한 OCR·버튼 확인과 Windows 파일 오류 및 화면 전환
모의 재현을 Codex에서 수행했습니다. 실제 Windows 및 MuMu 장시간
플레이는 미검증입니다.

Codex 소스 검사 130개와 배포 코드 검사 127개를 통과했습니다.
