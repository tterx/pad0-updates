# v1.0.139 · 달인 다색 크리스탈 결과의 다음 버튼 재시도

252번은 v1.0.137에서 발생했습니다. 달인 다색 2-7 자동 파밍이
크리스탈 보유 한도 안내가 있는 결과를 집계했고, 목표 재료의 추가
수량은 없었습니다. 목록 맨 아래에서 ‘다음’을 누르고 뗀 기록은
있으나, 마지막 캡처에서는 같은 보상 카드 목록이 맨 위에
표시됐습니다. 저장된 보상 화면과 마지막 캡처의 카드 영역은
167.5픽셀을 맞춰 보면 일치합니다. 첫 입력이 화면을 넘기지 못한
이유는 기록만으로 확인되지 않습니다.

달인 다색 재료 파밍의 집계 완료 화면에서 ‘다음’을 한 번 보낸 뒤
3초가 지나도 같은 화면이 보이면 새 화면을 한 장 더 확인합니다.
현재 회차의 집계가 장부에 남아 있고, 같은 크리스탈 패널과 카드의
겹치는 부분, ‘다음’ 위치가 확인된 경우에만 한 번 더 누릅니다.
스크롤 위치가 바뀌어도 카드가 일치하면 같은 결과로 처리합니다.
이어서 같은 던전을 돌 때와 다음 재료로 넘어갈 때 적용합니다.
보상 집계는 이미 저장된 회차를 그대로 사용합니다.

Codex에서 252번의 두 화면과 마나 보상 화면을 판독했습니다.
모의 테스트에서 재시도 한 번, 단일 회차 집계, F10 취소와 다른
화면에서 입력 차단을 확인했습니다. Windows와 MuMu 실플레이는
미검증입니다.

Codex 소스 검사 77개와 배포 코드 검사 74개를 통과했습니다.
