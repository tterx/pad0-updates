# v1.0.140 · 달인 다색 마지막 재료 선택과 완료 확인

254번의 네 번째 재료는 75개로 충족됐고, 다섯 번째 킹 메탈드래곤은
필요 90개 중 7개였습니다. 등록된 대상의 돌파 확인창까지 돌아갔으나
고정 판독 영역에서는 이 화면의 오른쪽 카드가 잘렸습니다. 필요 수량
표시의 위치를 찾아 판독 영역을 옮겨 카드 크기를 유지합니다. 다음
재료를 누르기 전에 새 화면의 카드와 좌표를 다시 확인합니다.

장부로 목표를 충족하면 연전 확인에서 종료합니다. 계속 파밍하는
중에는 크리스탈 보상 10회 집계 후 재료 확인창의 보유 수량을 다시
확인합니다. 재료를 바꾸거나 이미 재료 확인창을 열 때도 확인합니다.
대상과 선택 재료의 확인된 보유량이 두 화면에서 모두 목표를
충족하면 새 판에 들어가지 않고 종료합니다. 완료 알림에는 이때
확인한 수량을 표시합니다. F7로 등록한 기준 수량과 이미 집계한
보상 내역은 이 확인과 별도로 보존됩니다. 계속 파밍해야 하면 이전
스테이지의 정확한 ID가 획득 목록에서 확인될 때 우선 사용하며
기존 EX 선택 우선순위를 적용합니다.

Codex에서 254번의 실제 보유 수량 31·45·70·75·7과 오른쪽 카드
위치를 확인했습니다. 이 화면에서 선택 재료가 4번과 5번이면 아직
부족하며, 4번만 선택한 경우에는 완료로 확인됩니다. 253번은 스킬
‘사용하기’ 뒤 팝업이 남아 중지된 별도 사례입니다. 실제 Windows·MuMu
장시간 파밍은 미검증입니다.

Codex 소스 검사 91개와 배포 코드 검사 88개를 통과했습니다.
