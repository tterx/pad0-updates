# v1.0.141 · 달인 다색 한 재료 연전

255번은 킹 메탈드래곤 하나를 선택해 5-4에서 파밍하던 기록입니다.
장부에는 목표 90개 중 11개가 있었고, 다음 재료로 전환할 이유는
없었습니다. v1.0.140의 보상 10회 중간 확인이 연전을 종료하고
초 한계 돌파 확인창으로 돌아갔습니다. 거기서 새 화면의 카드
재확인에 실패했고, 추가 전투를 시작하기 전에 파밍이 멈췄습니다.
오류 ZIP에는 최종 화면만 있어 두 번째 프레임에서 어떤 조건이
달라졌는지는 확정하기 어렵습니다.

한 재료를 선택한 달인 다색 파밍은 보상 수량을 장부에 집계하면서
같은 스테이지를 연전합니다. 선택한 목표의 수량이 충족되면 연전을
종료합니다. 보상 10회 중간 보유량 확인은 여러 재료를 선택한
파밍에서 적용합니다.

Codex에서 재료 두 개를 등록하고 하나만 선택한 모의 실행이 같은
스테이지를 11회 진행하고 목표 충족 직후 종료하는 것을 확인했습니다.
두 재료를 선택한 모의 실행은 열 번째 집계 뒤 보유량 확인으로
진행했습니다. 실제 Windows와 MuMu 연전은 미검증입니다.

Codex 소스 검사 84개와 배포 코드 검사 81개를 통과했습니다.
