달인다속에서 잠금·가시가 겹친 드롭의 인식과 시작 확인, F10 수동 버튼 표시를 수정했습니다.

- 잠금 독을 빛으로, 잠금+가시 방해를 물로 오인하던 경우와 일부 가시 누락을 수정했습니다. 모든 칸이 같은 종류·상태여도 실제 드롭 무늬와 잠금·가시 근거로 퍼즐판을 확인합니다.
- 잠금+가시 드롭을 실제로 잡았는데 시작 확인에서 멈추던 경우를 수정했습니다. 원래 드롭 무늬·들린 잠금·주변 판의 안정성을 함께 확인하며 입력 간격과 최종 확인 조건은 유지합니다.
- F10 수동 전환 시 남은 마우스 캡처와 경로 표시를 해제합니다. 메인 창 최소화에 수동 버튼이 함께 숨는 문제를 수정했습니다.
- 패치는 달인다속에 한정했습니다. 최대 콤보 우선, 회복 동시 루트 제외, 기존 분기·EX 선택은 유지합니다.
