달인다속에서 모든 드롭을 공통 학습 보정으로 읽도록 반영했습니다.

- 불·물·나무·빛·어둠·회복·방해·독의8종과 일반·잠금·가시·잠금+가시 상태를 학습했습니다. 원본 타일의 학습/검증 분리를 확인하고, 고정된 가중치로 보정합니다. 불확실한 결과는 기존 판독을 유지합니다.
- 종류를 맞힌 것만으로 이동하지 않습니다. 실제 들린 원본 무늬, 새로 나타난 픽셀, 이동한 잠금·가시 표시와 주변 판의 정지를 함께 확인합니다. 218번의 실제 저장 화면은 이전 시작 확인4회 실패에서 새 버전1회 확인으로 바뀌었습니다. 같은7초 예산의 모의 입력에서 DOWN1회·이동116회·UP1회를 완료했습니다.
- 계산 버튼의 판 확인은 학습된 판에서 빠른 모델 경로를 우선 사용합니다. 메뉴·가림·오래된 화면 차단과 기존 불확실 판의 확인 경로는 유지합니다. 218번 전체 판은 보수적인 기존 경로를 사용하며 F10 실기 깜빡임 해결을 확정하는 검증은 아닙니다.
