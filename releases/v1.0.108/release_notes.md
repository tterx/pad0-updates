달인다속 수동 파티 읽기에서 상세가 열려 있는데 작은 스킬 표제를 놓쳐 멈추던 경로와 오류 ZIP이 저장되지 않던 경로를 수정했습니다.

- 전체 화면에서 표제를 못 읽으면 실제 청록색 글자 영역을 원본/대비 보정 두 영상으로 읽습니다. 두 영상이 모두 높은 신뢰도로 스킬 표제임을 확인해야 하며, 새로 캡처한 다음 상세에서도 확인합니다. 캐릭터 번호의 독립 2회 일치 검사는 유지합니다.
- 수동 읽기 실패는 입력/캡처 정리를 시도한 뒤 실제 상세 이미지·슬롯·OCR 결과를 오류 ZIP으로 저장하고 경로를 표시합니다. 저장 실패도 별도 표시합니다. 취소/옛 작업의 결과는 새 작업을 덮어쓰지 않습니다.
- 배포 소스의 불필요한 공백만 줄이고 전체 실행 AST가 같은지 확인하여 기존 2 MiB 업데이트 제한을 지켰습니다.

새 검사27개, 관련 로컬 215개, 실제 배포 소스 156개, Windows 1,437개가 생략 없이 통과했습니다. 실제 게임 글꼴 표제 OCR과 통제된 번호/상세 토큰으로 이전/수정 경로를 비교하고, 수동 작업자의 실제 ZIP 생성까지 확인했습니다. 현재 대화의 전체 스크린샷과 실제 MuMu 파티 등록 완료는 미검증입니다.
