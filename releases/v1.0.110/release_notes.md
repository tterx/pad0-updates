달인다속 수동 플레이에서 스킬을 사용한 뒤 퍼즐판이 보여도 계산 버튼이 사라지던 경로를 수정했습니다.

- 버튼 표시가 이전 판의 인식/계산 준비 상태에 막혀 현재 퍼즐판 확인 자체를 시작하지 못하던 조건을 분리했습니다. 경로가 아직 없어도 현재 퍼즐판이 확인되면 계산 버튼을 복구합니다.
- 일시적인 전체 판독 실패가 현재 퍼즐판의 긍정 확인을 덮어써 버튼을 숨기지 않습니다. 메뉴·다른 창·오래된 캡처·다른 영역/모드에서는 계속 숨기며, 명확한 비전투 화면은 옛 확인 결과를 무효화합니다. F10 이후 수동 상태와 F9 숨김도 유지합니다.
- 새 판을 아직 읽는 중에 버튼을 누르면 이전 계산을 폐기하고 판 읽기를 요청합니다. 기존12초 한도 안에서 완전한 새 판을 확인한 뒤 경로를 준비하며, 준비가 끝나도 실행은 다시 눌러야 합니다. 버튼 표시나 준비 완료만으로 드롭을 움직이지 않습니다.

새 검사21개, 관련 로컬 198개, 실제 배포 소스 148개, Windows 1,485개가 생략 없이 통과했습니다. 실제 게임 그림으로 구성한 판과 실제 캡처 작업자·Tk 버튼을 사용한 스킬 창 전환 재현에서 구버전은 이후46회 모두 숨겨졌고 수정본은46회 모두 표시됐습니다. 두 버전 모두 메뉴에서 숨겼고, 수정본 버튼 클릭은 새 판 읽기만 요청했습니다. 캡처·포커스·스킬/준비 상태 전환은 통제했으며, 현재 대화의 정확한 전체 스크린샷과 실제 MuMu 실행은 미검증입니다.
