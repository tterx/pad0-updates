달인다속을 처음부터 수동으로 플레이할 때 계산 버튼이 없고 F6도 진행되지 않던 초기화 경로를 보완했습니다.

- 일반 수동 상태에는 F10 이후에만 있던 전체 게임 화면의 퍼즐 좌표 확인이 빠져 있었습니다. 이제 F10 없이도 현재 게임 화면에서 확인한 퍼즐판으로 좌표를 잡고, 창 이동·크기 변경으로 예전 절대 좌표와 달라졌을 때도 갱신합니다.
- 좌표를 채택하기 전에 현재 창 식별자·크기·포커스·가림과 실제 퍼즐판 영역을 확인합니다. 다른 창·메뉴·오래된 캡처·바뀐 작업·자동 실행 중에는 채택하지 않습니다. F9와 임시 숨김 설정을 강제로 풀지 않습니다.
- 좌표가 없는 상태의 F6 대기가 즉시 취소되던 조건을 수정했습니다. 전체 화면 확인을 깨우고, 확인된 새 좌표만 기존 요청에 연결합니다. 기존12초 한도는 연장하지 않으며 준비가 끝나도 실행은 다시 눌러야 합니다.
- F12 버튼 미표시 진단에는 좌표 채택/거부 이유와 현재 화면 확인 결과를 함께 남깁니다. 다른 모드와 F10 전환, 콤보 정책·드롭 모델·입력 검사는 유지합니다.

새 검사21개, 관련 로컬 219개, 실제 배포 소스 169개, Windows 1,506개가 생략 없이 통과했습니다. 초기 수동 시작·F6으로 시작·창 이동 후 시작의 세 재현에서 구버전은 좌표와 버튼을 복구하지 못했고 수정본은 모두 복구했습니다. 실제 좌표 변환·가림 판별 함수·전체 화면 작업자·UI 큐·F6 폴링과 Tk 버튼을 사용했으며, OS 응답·캡처·화면 제목 판별은 통제했습니다. 현재 사용자 기기의 상태와 실제 MuMu 동작은 미검증입니다.
