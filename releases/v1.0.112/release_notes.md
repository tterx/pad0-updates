달인다속 수동 계산 버튼과221번 방해 드롭 확인을 수정했습니다.

- 실제 첨부 화면으로 재현한 결과, 버튼 표시 검사가 무거워 자체 유효시간을 넘기면서 깜빡이거나 나타나지 않을 수 있었습니다. 일반 퍼즐판은 기존 격자·드롭 테두리·질감 검사를 작은 미리보기로 먼저 확인합니다. 기존1.2초 유효시간과 다른 창·가림·메뉴 검사는 유지합니다.
- 221번은 마지막 방해 드롭의 실제 위치가 거친 탐색 간격 사이에 있어 정밀 탐색이 시작되지 않았습니다. 달인다속에서 정밀 탐색의 시작 후보만 보완하고, 양쪽 눈·새로 나타난 픽셀·윤곽·물 드롭 거부·나머지29칸·전체 입력 기록과 손 떼기 후 반응 검사는 유지합니다.
- 222번은 별도 조작 없는 자동 실행 중, 손 떼기 전 화면에 이미6콤보 공격이 진행되고 있었습니다. 입력 유지가 왜 끊겼는지는 아직 확정하지 못했습니다. 해결됐다고 처리하거나 이동을 재시도하지 않으며, 이 상태를 별도 원인으로 기록합니다.
- F12 진단에 표시 제한 상태와 작업 중 오류를 추가했습니다.
