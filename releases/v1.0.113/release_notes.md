달인다속 수동 플레이의 속성 판독·조건 확인·계산 준비에서 경쟁하던 중복 작업을 줄였습니다.

- 새로 캡처한 픽셀이 완전히 같을 때만 기존 속성·가림 판독 결과를 재사용합니다. 화면 전체 픽셀의 SHA256, 크기, 좌표, 작업·인식 세대와 모델을 확인합니다. 캡처 시간과 두 번의 독립된 판 확인 조건은 유지합니다.
- 현재 게임 창·좌표에서 퍼즐판이 실제로 확인된 동안에는 별도의 전체 화면 메뉴/퍼즐판 재판독을 쉬도록 했습니다. 판이 사라지거나 확인 결과가 오래됐을 때, 창 이동·크기 변경·최초 시작 때는 기존 전체 화면 확인을 재개합니다.
- 조건 확인 과정의 같은 캡처에 대한 속성·구름/암흑 재판독도 공유합니다. 최대 콤보 탐색과 시간 한도, 이동 속도, 최종 실행 전 판·시간·적 조건 검사는 유지합니다. 다른 모드는 기존 동작을 유지합니다.
- F12 진단에 동일 픽셀 재사용 횟수를 추가했습니다.
