달인다속 수동 판독의 공용 잠금 대기와 최초 계산 버튼 준비 경로를 보완했습니다.

- 이전 버전에서는 새 화면의 무거운 판독이 공용 잠금을 잡아 이미 읽은 동일 화면까지 기다리게 했습니다. 판독을 잠금 밖으로 옮기고 이전 세대의 늦은 결과는 캐시에 넣지 않습니다.
- 최초 계산 버튼은 전체 화면 제목 OCR을 기다리지 않고 후보 퍼즐판의 실제 픽셀을 먼저 확인합니다. 현재 게임 창·좌표·가림·화면 유효시간을 검사한 뒤에만 좌표를 채택합니다. 속성 판독과 실행 전 검사는 그대로 거칩니다.
- 캡처가 끝난 뒤 드롭을 읽는 동안에는 ‘퍼즐판 확인 중’으로 표시합니다. F6 대기 기한, F10 수동 상태, 최대 콤보 탐색·입력·최종 실행 검사는 유지합니다. 다른 모드는 기존 동작을 유지합니다.
