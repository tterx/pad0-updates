달인다속 수동 포커스·새 판 표시·오류 저장을 보완했습니다.

- PAD0 본체를 클릭한 상태도 버튼 표시 대상으로 허용합니다. 퍼즐판의 실제 존재와 가림 검사는 유지합니다.
- 스킬 등으로 판이 바뀌면 첫 판독에서 이전 계산·준비 상태·속성 부족 표시를 지웁니다. 새 판이 두 번 일치한 뒤 다시 준비 완료로 전환합니다.
- F12는 전면 창·캡처·판독·작업 대기와 별개로 상태 진단 ZIP을 남깁니다. 조건/판 원본이 없어도 이전 이미지를 붙이지 않는 상태 ZIP을 저장합니다. 상태·계산 조회 일부가 실패해도 오류를 기록합니다.

새 회귀9개, 실제 배포 코드 147개, Windows 1,552개가 생략 없이 통과했습니다. 드롭 모델·최대 콤보 목표·탐색 예산·입력·최종 실행 검사는 유지합니다. 첨부 기록에는 실제 드롭 이미지와 내부 판독이 없어 실기 색상 오인식/탐색 실패 전체의 해소는 미검증입니다. [검증 범위](https://github.com/tterx/pad0-updates/blob/main/docs/reviews/REVIEW323.md)

PAD0를 완전히 종료한 뒤 시작.vbs를 다시 실행하면 업데이트됩니다. 설정·수량·분기 기록은 유지됩니다.
