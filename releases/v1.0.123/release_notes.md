달인다속 자동플레이에서 이동 오차로 던전 전체를 중단하지 않고, 던전 패배 때만 코너 대기를 보정합니다.

- 원래 잡은 드롭·전체 이동 기록·손 떼기가 확인된 경로 오차는 실패 기록으로 남기고 던전을 계속 진행합니다. 잘못된 배치를 성공으로 처리하거나 경로를 다시 누르지 않습니다.
- 실제 HP 0·패배 안내가 확인될 때마다 코너 대기를 10ms씩 누적해 기존 재도전 흐름으로 진행합니다. 이동 오차나 승리만으로는 대기를 늘리지 않습니다. 같은 패배 화면에는 한 번만 적용합니다.
- 기기별 보정값을 저장·재사용하고, 추가 대기는 SDK 기본 코너 대기 이후에 더합니다. 직선 이동 간격은 유지합니다.
- 추가 대기를 경로 시간 계산에 반영하며 4초 잔여를 확보합니다. 그 시간에 들어갈 경로가 없으면 실행을 보류합니다. F10·통신·손 떼기 실패는 계속 중지하며 Windows 수동 이동과 다른 모드는 유지합니다.
