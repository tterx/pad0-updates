달인다속 재료 파밍 중 MuMu 홈으로 돌아가면 같은 기기에서 Puzzle & Dragons 0를 다시 실행합니다. GungHo 로고, 시작 버튼과 1번 저장 데이터를 확인해 누르고, 잠입 중인 던전 재도전 안내가 뜨면 아니요를 누릅니다. 육성 검색에서 공백을 뺀 이름을 사용해 기존 대상의 파밍을 이어갑니다.

중단된 판은 새 보상이나 패배로 집계하지 않습니다. F10으로 중지할 수 있습니다.

Codex 관련 검사 461개와 배포 코드 검사 222개를 통과했습니다. Windows/MuMu 실기 재접속은 미검증입니다. [원인·검증 범위](https://github.com/tterx/pad0-updates/blob/main/docs/reviews/REVIEW335.md)
