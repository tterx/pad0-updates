달인 다색 재접속에서 제목 화면의 시작 버튼 글자를 더 좁게 판독해 장식으로 인한 오인식을 줄였습니다. 겅호 로고와 시작 버튼은 각각 새 화면 두 장에서 확인한 뒤 클릭합니다. 재접속 진단에 로고·시작 최초 인식과 클릭 요청 시각을 기록합니다.

첨부 화면 판독과 Codex 소스 검사 63개 및 배포 코드 검사 60개를 통과했습니다. 실제 Windows와 MuMu 재접속은 미검증입니다. [원인과 검증 범위](https://github.com/tterx/pad0-updates/blob/main/docs/reviews/REVIEW346.md)
